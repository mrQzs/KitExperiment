## 执行记录字段

每条结果必须记录：`case_id`、`requirement_refs`、`target_ref`、`environment_id`、`fixture_source`、`command_ref`、`started_at`、`finished_at`、`oracle`、`observation`、`artifact_refs`、`cleanup`、`status`、`failure_code`、`operator`、`reviewer`。

## 状态规则

- `PASS` 只表示该 case 的 oracle 在固定 target 上满足，不能推导项目已集成。
- `FAIL` 表示真实执行且观察不满足 oracle。
- `NOT_RUN` 表示缺少平台、CLI、授权、预算或其他前置条件。
- `BLOCKED` 表示输入、锁、代际或安全门禁阻止执行。
- `ERROR`、`SKIPPED`、`CANCELLED`、`WAIVED`、`STALE` 不计入通过。
- 离线、真实 CLI、真实 OS 证据必须分栏统计；12 的 IT01–IT36 仍需独立登记。
