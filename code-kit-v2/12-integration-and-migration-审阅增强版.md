## 1. 目标与非目标

**原文保留**

证明模块 01–11 组合后仍保留现有门禁，能在声明的平台和 CLI 组合上完成完整任务链路。
为现有 Pi 用户提供可审阅、可回退、不会重写历史证据的迁移路径。
让交付状态精确到平台、CLI、角色与工作流，明确已验证、未验证和受限范围。

- 包含：核心回归、完整链路、三平台验证、异构 CLI、旧数据读取和迁移手册。
- 包含：检查技能源与生成副本、规则基线及新增保护路径的一致性。
- 不包含：默认授权安装依赖、联网调用模型、提交、推送、合并或发布。
- 不包含：以只有 stub 的结果宣称真实 CLI 接入完成，或承诺所有平台强杀后无残留。
- 不要求 [13 Observer](13-optional-observer.md)启用；核心交付不依赖额外摘要模型。

**审阅补充**

### 1.2 完成定义与四个独立结论

本模块完成时应交付四种相互关联、不可互相替代的结论：

1. **证据完整性**：目录、来源、字节、候选、环境和所需场景均可核对。
2. **交付范围结论**：主模型依据固定证据，明确完整交付、部分交付或阻塞及其边界。
3. **迁移操作结果**：哪些受审变更实际应用、哪些未执行、是否完成恢复演练。
4. **当前动作准入**：执行、安装、代码外发、费用、提交、合并、发布等仍由 03/07 和既有授权判定。

一个参考程序返回 `evidence_readiness=COMPLETE`，最多表示对**调用方提供的受信目录**得到了满足其规则的证据；不表示项目 PASS，更不提供 `can_dispatch=true`。目录完整性、来源真实性、业务内容质量和当前权限仍是外部前置条件。

### 1.4 非目标的实施解释

本版不把“迁移文档”扩展成自动维护所有仓库的工具；不实现第二 CLI、不重写 03/05/07/09；不在附录自动执行模型生成的命令。必要的源码、规则和技能变更属于受保护维护路径，普通执行器不能通过把文件加入 Scope 取得权限。

“可回退”首先指**停止新派遣并切回已授权选择**，不是撤销已经发出的网络请求、追回已发生费用，或让旧代码完整理解新版数据。不能保证的恢复部分必须逐项列明。

### 2.4 发布依赖与无环引用

```text
候选 / 配置 / 规则 / 插件 / 环境 / 检查目录
                ↓
        各次检查原始证据与观察
                ↓
      EvidenceManifest + CoverageReport
                ↓
        主模型 DeliveryDecision
                ↓
           交付登记回执
```

Manifest 不包含自身摘要，也不反向包含引用了该 Manifest 的最终决定；对外交付可用单独索引引用二者。迁移计划先有固定预览与备份引用，再由独立审核记录引用计划。审核后不能向计划回填新 `approval_id`；需要关联时使用独立执行记录。

### 3.1 原文记载与本次核验范围

本节开头的“现有”来自原文，不是本次仓库源码审计。实际 `tests/test_dispatch.py`、G0–G6、`_WinJob`、`sync-adapters`、旧 profile 解析优先级都应在实施时重新取证。不得因为本系列的参考包能运行，就认为已取得目标仓库基线。

区分三种基线：**旧行为基准 B**用于回归对照；**集成候选 C**用于本轮验收；**迁移现场 U**包含用户当前配置、未提交工作和历史状态。C 的代码合格不能证明 U 能安全迁移，B 的已知失败也不能把 C 的相同失败改记为通过。

### 3.2 基线报告必须记录的内容

记录真实仓库身份、Git 对象格式、完整 commit/tree、候选或补丁来源、受保护规则摘要、未提交和未跟踪范围、子模块与 LFS 状态、Python/Git/CLI/适配器版本、检查定义、相关依赖锁、实际命令、环境和时间。每项标 `measured / source_reported / inferred / unknown`。

原 01 的设计调查提交只作历史线索，不直接作为将来的运行基线。无法解析目标提交、候选内容未固定或存在来源不明差异时，先阻塞验收，不用 HEAD 当前值偷偷替换。

### 3.3 历史行为差分表

| 差分对象 | 对照方式 | 禁止的“修复” |
|---|---|---|
| 合同 v1 默认值与拒绝 | 同一原字节输入旧/新兼容读取器，对比关键结构与错误 | 先修改 fixture 适应新读取器 |
| Pi 模型与 thinking | 对照原已授权解析结果、冲突规则和实际证据 | 把 Step/high 换成当前默认 |
| wait 和退出码 | 对照 0/1/2/3/4 的旧语义，wait=3 继续表示在运行 | 统一压为成功/失败 |
| G0–G6 / 独立检查 | 从实际基准提取输入、预期拒绝原因与证据 | 为迁移新增宽松旁路 |
| 历史读取 | 比较来源、状态、模型未知值和费用未知值 | 补造当年审核、模型或费用 |
| 技能与生成副本 | 同步器固定版本、源清单、生成清单、漂移报告 | 直接修改副本使表面一致 |

精确的 G0–G6 名称及实现判定必须来自真实源码，本版不重新定义它们。迁移发现旧缺陷时按缺陷处理，记录修复授权与新预期，不能悄悄改“兼容”的含义。

## 4. 接口和行为约束

### 4.1 集成验收单位

**原文保留**

以具体候选树、合同、有效配置、插件锁和环境锁共同确定一次验收输入。
合并或重放导致候选变化时重新验证有关检查，不沿用旧候选的通过结论。
主模型依据独立检查和原始证据给结论；执行 CLI、planner 或 observer 不给自己最终验收。
用量按 `request_id` 汇总全部可观测角色；不可观测的当前主会话成本保留 `unknown`。
在相同口径和可观测数据不足时，不承诺主模型 token 占比或整体降费比例。
把规划和执行交给 CLI 会转移工作量，但摘要、交接和返工可能增加总 token，不能直接认定整体消耗下降。

**审阅补充**

#### 4.1.1 IntegrationTarget：验收对象不是一个可变分支名

建议正式记录至少包含下列字段；这是生产字段草案，不表示附录已实现全部验证：

| 字段 | 规则 |
|---|---|
| record_type / schema_version | 独立记录家族与版本；未知版本拒绝 |
| integration_id / repository_id / request_id | 稳定身份；request 继续是预算根 |
| base_ref / candidate_ref | 由既有机制封存的实际基线与候选；不得用预计 SHA |
| contract_refs | 本轮正式 MD/JSON 成对引用与版本 |
| config_ref / plugin_lock_ref / rule_refs | 实际所选依赖；无插件时按已审策略明确不适用，不伪造空锁 |
| check_catalog_ref / checker_refs | 完整检查集合、测试代码、比较器与判定规则 |
| environment_refs / adapter_refs | 每个矩阵实例的精确环境及适配器/协议 |
| dependency_refs | 声明输入的传递闭包；由受信解析器重算 |
| source_binding_versions | 采用前序代际设计时记录可信版本，不从 mtime 猜测 |
| scope_ref | 本次承诺的平台、CLI、角色、工作流与保证边界 |

同一集成轮次可以含多个环境下的子目标，它们应共享同一固定产品候选，并分别绑定各自环境。不能把 Windows 的环境引用换成 Linux 的 hash，也不能拿 C1 的 Linux 与 C2 的 Windows 测试拼成 C2 三平台通过。

候选未提交也必须使用已有固定 tree/补丁机制；不能为满足报告格式擅自创建 commit。需要获授权的提交/合并时，完成后对实际新候选重验相关检查。[^P01][^P07][^P12]

#### 4.1.2 冻结顺序与变更失效

```text
审定范围及采用项 → 冻结代码/规则/技能源/副本
 → 冻结检查目录与每个平台输入 → 运行检查
 → 封存原始证据 → 核验成员与来源 → 计算覆盖
 → 主模型审阅 → 登记交付结论 → 当前动作另行准入
```

| 变化 | 旧结果如何保留 | 新轮次如何处理 |
|---|---|---|
| merge/rebase/重放改变候选 | 历史检查仍证明旧候选 | 新候选建立新 target；按依赖重验 |
| 检查脚本/断言/基线/变异定义改变 | 原结果不改 | 重新绑定检查集，不用旧测试次数作证明 |
| 角色模型、参数、工具、插件或相关规则改变 | 原运行仍存在 | 02/03 重新解析、锁定及审核 |
| 入口/解释器/CLI build/必要 shell 改变 | 旧平台结果保留 | 新环境预检；不能仅比较版本字符串 |
| 证据仅被搬运 | 旧引用完整保留 | 使用独立定位映射重新核验，不擅改原引用 |
| 文档最终文字修改 | 属于新候选差异 | 记录影响分析；不能声称发布字节仍是原被测候选 |
| 新无关进度事件 | 不使业务检查失效 | 只更新展示，不全局重新审核 |

跨候选复用只允许依据已审的依赖分析形成**新复用决定**，明确哪些不变量未变；缺少可证明规则时重跑。安全边界、解析器、权限和来源规则变更建议扩大重验范围，不能只按文件交集判断。

#### 4.1.3 CheckCatalog 和 CheckObservation

`CheckCatalog` 在执行前由受信维护流程冻结。每个 case 至少记录 `case_id`、原要求编号、场景说明、目标引用、所需环境、执行命令引用、预期观察/错误、证据类别、是否必需、必要审阅者和超时预算。一个 A 编号可以展开成多个 case；例如 12-A04 必须包含三平台的实际场景，不是一条布尔值。

`CheckObservation` 至少记录一次尝试 ID、case/target、命令与执行事实、退出码/信号、stdout/stderr 引用、协议与采集完整性、环境、预期结果比较、观察结论和失败理由。完整版本还应带时间、采集器版本、原始来源、父 request/operation；附录小型记录只展示归约必需字段，完整生产适配仍待实现。

必须区分：**测试预期系统拒绝某输入，且实际按预期拒绝**，可以记该负向测试 PASS；但该输入对应的业务任务仍是拒绝，不是执行通过。非零退出只有与冻结 oracle 匹配，才能成为预期负例；超时、解释器崩溃、测试未收集不能误算“成功发现缺陷”。[^P08]

#### 4.1.4 状态、来源与有效性分层

| 层次 | 建议值 | 用途 |
|---|---|---|
| 运行结局 | NOT_RUN / RUNNING / EXITED / CANCELLED / START_UNKNOWN | 发生了什么进程事实 |
| 测试观察 | PASS / FAIL / ERROR / SKIPPED / INCOMPLETE | 是否符合具体测试 oracle |
| 来源验证 | VERIFIED / UNVERIFIED_SOURCE / CONFLICT | 来源能否由受信采集路径核实 |
| 输入有效性 | CURRENT / STALE / STALE_ENVIRONMENT | 是否匹配本次固定目标 |
| 例外处理 | NONE / REQUESTED / ACCEPTED_EXCEPTION / EXPIRED | 业务是否接受明确缺口 |
| 证据就绪 | COMPLETE / PARTIAL / NONE / BLOCKED | 仅为目录证据汇总 |

`NOT_IMPLEMENTED` 指功能尚不存在，不能与“实现存在但未测”的 `NOT_RUN` 混写。`WAIVED`/例外不变成 PASS；`N/A` 只适用于事前已确定、确实不适用的扩展场景。原 12-A04/12-A05 不能因环境或预算不足改为 N/A。

来源类型分为合成、加工自真实、真实捕获、本机观察和文档/源码调查；本机帮助输出能说明版本或接口，不证明实际模型调用的身份、费用和取消。哈希正确只证明字节符合引用，不证明它来自真实平台。采集器身份、环境匹配及必要真实性检查必须单独验证。

#### 4.1.5 无遗漏的汇总算法

```text
1. 从批准的 scope 与已采用要求获取受信期望目录，不相信报告自带分母。
2. 对目录、本次目标、环境及检查规则核验来源与完整引用。
3. 为每个期望 case 找到明确选定的尝试；没有记录就记 NOT_RUN。
4. 核验记录 ID 的重复/冲突，目标、环境、来源类别与证据成员。
5. 选择规则由受信计划指定，不按最大时间戳或“最后一个 PASS”挑选。
6. 旧 FAIL/ERROR 和所有重试保留；未解决的失败不能被后来 PASS 掩盖。
7. 必需项逐项 AND；任一缺失、过期、例外、错误或未解决失败都不完整。
8. 输出满足项、全部缺口、历史失败、例外及补证责任；不输出派遣许可。
```

同一稳定记录 ID 的相同字节重放不增加已完成数；同 ID 不同内容是完整性冲突。不同 attempt 中内容相同的日志不是同一次执行，不能按内容 hash 去重调用次数或费用。

全局目录签名/信任入口损坏、证据成员被替换等情况应产生 `BLOCKED`，不得只当“少一个可选文件”。附录对结构冲突抛出明确异常；上层须把该异常映射为阻塞报告，而不是捕获后用空列表继续。

#### 4.1.6 重试、旧失败和例外接受

不允许“重跑到绿”为默认策略。重试必须引用失败归因、允许的次数/费用、是否相同目标、重跑原因和旧记录。基础设施故障也保留 ERROR 与来源；修复代码、检查或环境后会产生新 target 或新环境，不可与原失败混作同一不变输入。

例外记录包含准确 case/target、风险、补偿、批准来源、期限、到期动作和受限交付范围。例外接受可以支持**带缺口的部分交付**，不能证明缺失的实机/真实 CLI 能力，也不能批准核心授权绕过或历史证据修改。例外过期、依赖变更或被撤销后，重新判断当前可用范围；不抹掉当时的接受事实。

#### 4.1.7 结论与发布分开

机器 CoverageReport 只提供证据状态；主模型 DeliveryDecision 记录 `FULL / PARTIAL / BLOCKED / WITHDRAWN`、准确 scope、依据、限制和未决项。任何结论都不代替 03 的执行或集成许可。审核结论也不应写入被它引用的 Manifest 造成循环。

建议报告抬头固定显示“目标、候选、观察时间、证据类别、原要求完成情况、额外声明范围、当前限制”。能力表可写“某精确平台和角色已验证”；不得省略版本与限制后写“全面支持”。先接受的部分范围不改变原核心目标仍未全完成的事实。

#### 4.1.8 证据封存、导出与读取

先收集并核验预期成员，再生成确定排序的 Manifest。每项包含完整 ResourceRef、字节数、证据用途/分级和关联检查；生成后逐文件核对，并核验**实际成员集合等于受信期望集合**。只遍历报告自己列的成员，无法发现报告删掉了失败证据。

导出仅限经批准的闭包；不递归打包整个仓库、HOME、凭据、完整环境或 `.agent/`。脱敏属于新视图，记录规则和来源关系；不得把脱敏重写后的字节冒充原始保留流。密钥不进入低熵 hash“脱敏字段”；需要保留的私密原证据按既有访问控制保存。

归档接收需拒绝绝对路径、路径穿越、重复目标、大小写/Unicode 碰撞、符号链接和特殊文件，限制文件数、单文件/总大小与展开比。附录只验证内存中的字节映射，**不实现安全压缩包提取或恶意并发文件读取**。

封存过程遵循“临时对象→写完/同步→校验→不可变对象→登记引用”；失败留下可诊断孤儿，不发布可读的虚假成功。`os.replace` 的名称替换原子性不等于多文件事务或断电持久性，需要目标平台分别验证。[^W01]

若用 CI artifact 传输，仍须执行本模块自己的成员/摘要拒绝检查。GitHub 文档将 artifact digest 不匹配描述为日志/UI 警告，不能假设该警告已经替代项目的失败门禁。[^W02]

#### 4.2.2 支持矩阵键

支持记录建议使用：

`(产品候选, OS及版本, native/WSL/container, architecture, filesystem, Python/Git, CLI family/build, adapter/protocol, role, workflow, shell/version, config/environment refs)`。

原生 Linux 宿主的容器运行与发行版原生入口要分别标记；WSL 是单独 Linux 环境，不充当 Windows 原生证明。macOS ARM 与 x86、PowerShell 7 与 Windows PowerShell、Bash 与 zsh 的差异不靠枚举 OS 一笔带过。无法取得的环境明确 NOT_RUN，文档保持其待验位置。

不要求对所有可能组合做全笛卡尔积，但**每一个公开承诺组合**都必须有相应证据。风险导向抽样用于补充探索，不能把未测承诺单元格变绿。A→B 不证明 B→A，同 CLI 双 profile 不证明异构。[^P05][^P11]

#### 4.2.3 原生必测细目

| 子组 | 覆盖内容 | 观察要求 |
|---|---|---|
| 入口 | 中立 Python 与声明 wrapper、旧兼容入口 | 精确路径/解释器链、版本、原始退出码 |
| 参数 | 空参数、空格、中文、引号、反斜杠、特殊字符 | 子进程回显的参数数组逐项相等 |
| 文本 | CRLF/LF、UTF-8、末尾换行、无效输入 | 不偷偷改变已锁字节 |
| Shell | 已声明 Bash/zsh/PowerShell/cmd、缺失和版本不符 | 调度 shell 与 CLI 内部工具 shell 分开 |
| 监督 | 正常退出、普通取消、超时、输出上限、管道未 EOF | 退出、采集与后代清理独立记录 |
| 强杀 | 调度器突然退出、子进程脱离、PID 复用 | 残留检测、身份核验和恢复证据 |
| 文件 | 大小写、Unicode 路径、链接/junction、权限拒绝 | 真实文件系统事实，不靠平台字符串 |
| 恢复 | 再启动读取账本、未知状态隔离、重复操作 | 不重复创建 attempt/模型调用 |

Windows 的 Job 行为要结合实际创建/绑定、继承、breakaway 和嵌套配置验证；不能仅因为代码设置了 `KILL_ON_JOB_CLOSE` 就声称所有后代无条件消失。Microsoft 文档明确描述 Job 的成员与退出限制，项目保证应限定到实际受监督范围。[^W03]

POSIX 强杀后的全后代回收不在原文保证范围。正常取消的清理成功、主 PID 消失、stdout EOF 与“全部后代已退出”必须分开；测试不足时保留 `unknown/residual_detected`，不使用 `kill <未知PID>` 作为通用恢复步骤。[^P05]

#### 4.2.4 CI 是证据生产者，不是交付真相来源

CI 配置若纳入本次授权范围，建议矩阵禁用 fail-fast 以便完整收集目标环境结果，并为真实付费调用设独立、受控的准入步骤。GitHub Actions 的 fail-fast 与 continue-on-error 会影响其他 job 是否被取消及工作流表面状态；汇总器必须读取每个目标 job 的实际结果。[^W04]

只展示配置语义片段，不提供含未知版本的可直接部署工作流：

```yaml
strategy:
  fail-fast: false
  max-parallel: 3
# matrix.include 必须来自已审核的目标清单。
# 每行写明确 runner 镜像/架构/环境标识，不把 latest 当不可变版本。
# 必需检查不能配置 continue-on-error 来换取整体绿色。
```

每个 job 写唯一 `case_id/attempt_id/target_ref` 和环境事实；失败也上传受控日志，但“日志上传成功”不覆盖测试失败。聚合步骤必须在部分 job 失败后仍运行，并将未出现、被取消、无有效 artifact 的行保留为缺口。依赖下载、第三方 action 与镜像需要版本/摘要和供应链审阅；安装不是本文默认授权。

Windows job 即使跑在真实 Windows 上，测试命令内部使用 Bash 也不能证明“原生基础流程无需 Bash”。必须另外记录无 Bash 的约束与测试路径。真实凭据仅限受信任务，不提供给未受信 PR 内容或 arbitrary checkout 后运行的脚本。

#### 4.2.5 三类工作流的质量 oracle

缺陷修复需要“具体触发输入在旧实现表现错误、固定候选表现正确”的对照及范围/门禁，不以其余旧测试绿代替修复有效性。文档维护同时检查本地引用和内容；格式通过但描述与实际行为冲突时仍可拒绝。回归测试需对目标缺陷或受控变异有辨别力，语法错误、导入失败、未收集测试不能充当有效反测。[^P08]

候选冻结在写入后、独立检查前；同合同检查可读取尚未 PASS 的候选。调查已由规划完成且输入仍有效，可以消费固定调查产物，不为“完整链路”重复启动模型。跨任务才要求上游接受和真实基线使用许可。[^P07][^P08][^P09]

#### 4.2.6 一条真实异构链路应带齐什么

1. 同一 request 的目标、费用/代码外发授权、真实 profile 和两个独立环境锁。
2. A 的版本与真实调用来源、PlanningBundle、模型/工具/终止/用量证据。
3. 主模型对固定草稿/合同的审核；正式 MD/JSON 的原字节发布回执。
4. B 对正式合同的独立调用、身份与工具证据、固定候选和范围检查。
5. 独立检查及主模型 verdict/接受；必要时单独的集成使用许可。
6. 失败、返工、内部辅助调用和迟到费用的同 request 归属。

已完成的 A 规划和另一个需求的 B 执行不能拼成一条链路；只有 help 输出、模拟事件、自然语言自称型号或同一家 CLI 的两个路径也不满足 12-A05。当前未提供真实品牌和授权，本版不替用户选择或调用。[^P11]

#### 4.2.7 用量、性能与节省报告

只展示 07 的权威账本快照与游标，不重算入账。分别列已知 token/金额、小计覆盖范围、未知调用、未结算预留/敞口和币种；失败、取消和重试也保留真实消耗。主会话不可观测时写 `unknown`，不从剩余总额倒推。

比较成本或耗时需要相同任务集、输入规模、质量门槛、平台/模型、价格口径、缓存情况、重试规则和观察窗口。报告样本数、分布与失败比例；人工合成微基准不能宣传为真实模型节省。观测金额限额不是供应商硬停止；机械调用次数、并发和时限仍需落实。[^P07][^P10][^P12]

#### 4.2.8 覆盖计算示例

假设受信目录要求 12 个 case，9 个当前来源充分且 PASS、1 个 FAIL、1 个 NOT_RUN、1 个例外接受：`required_passed=9, required_total=12`。这是部分证据，不能以“已执行项通过率”隐藏未测与例外；例外批准仍不把 9 改成 10。若其中 3 个 PASS 来自旧候选，当前通过数应降为 6，并显示 3 个 STALE，而非改写旧记录。

附录的三 case 演示仅提供一条离线证据，另外两条原生/真实要求无记录，因此演示结果为 `PARTIAL, 1/3`。测试中模拟三条充分来源用于检验算法，但不构成真实平台/CLI 的证据。

### 4.3 迁移约束

**原文保留**

迁移前只读检查 schema、旧入口、实际 profile 选择与用户自定义配置，给出逐项变更预览。
v1 数据继续按旧 schema 解释，不重写旧合同、不重算历史哈希、不填造 v2 审核记录。
v2 新能力必须采用 v2 发布及锁定流程，不能伪装 v1 来避开新门禁。
保留已授权 Step/high 选择，改为显式 profile；迁移不得自动换 CLI、模型或思考级别。
本机路径只进入允许的 local 覆盖，权限、模型策略和插件信任不随机器路径覆盖。
新入口、插件、schema 和保护路径按阶段更新；启用前确保当前规则与运行基线匹配。
迁移步骤须可重复检查并识别已完成项，不因重跑重复注册插件或重复发布合同。

**审阅补充**

#### 4.3.1 迁移准入：先只读盘点，再审阅计划

预检不得解析或执行模型生成脚本。读取已批准路径上的旧配置/合同/元数据，记录版本、入口、有效模型、固定参数、用户定制、未提交工作、历史记录、活动运行及权限。CLI 的 `--help/--version` 也是执行程序，应作为 04/05 的单独批准探测，而非藏在“纯预检”中。

预检结果每项为 `READY / BLOCKED / UNKNOWN / NOT_APPLICABLE`，并带来源、修复方向、是否需要写权限/联网/费用。任何影响模型、工具、规则、信任或历史读取的 UNKNOWN 都不能以默认值完成映射。

| 预检项 | 必须输出 | 阻塞条件 |
|---|---|---|
| 现场身份 | repo/worktree、Git common dir、真实基线、工作区指纹 | 指向另一仓库或现场漂移 |
| 旧解析选择 | v1 schema、入口、provider/model/thinking、环境冲突结果 | 不知道当前有效模型或存在冲突 |
| 新读取能力 | 配置/合同/记录版本兼容矩阵 | 旧进程会误读新格式 |
| 用户工作 | 已暂存/未暂存/未跟踪及需保留忽略文件的清单 | 无法确定所有权或目标重名 |
| 历史证据 | 完整成员、原版本、字节核验与已有摘要字段 | 文件缺失或不一致未解释 |
| 运行状态 | active/START_UNKNOWN、清理、预算与未结算外发 | 仍有会被切换影响的运行 |
| 规则技能 | 现行基线、源、生成器与副本 | 未获授权或实际生效规则不匹配 |
| 备份恢复 | 存储目标、权限、恢复演练、保留策略 | 只能复制但未证明可恢复 |

#### 4.3.2 只读取证命令与输出解释

下面是后续操作手册的命令模板；本次未对用户仓库执行。以 05 已核验的 Git/Python 入口、受控 cwd 和允许环境执行，原始 stdout/stderr 单独保存，含路径的结果不公开整段粘贴：

```text
git --version
git rev-parse --show-object-format=storage
git rev-parse --verify --end-of-options HEAD^{commit}
git rev-parse --git-common-dir
git -c core.fsmonitor=false --no-optional-locks status --porcelain=v2 -z --untracked-files=all --ignore-submodules=none
git worktree list --porcelain -z
git diff --no-ext-diff --no-textconv --binary
git diff --cached --no-ext-diff --no-textconv --binary
git ls-files --others --exclude-standard -z
```

`status` 默认可能刷新 index 缓存；此处关闭可选锁及 fsmonitor，减少非必要副作用，但仍不将 Git 配置视为天然无风险输入。`status` 退出 0 不表示工作区干净，要解析其 NUL 分隔输出。diff 禁用外部 diff/textconv，避免把取证变成执行任意转换程序；差异输出可能含敏感内容，留在受控存储。[^W05][^W06]

这些命令不是完整备份，也不会发现全部忽略文件、所有凭据来源或远程 LFS 实体。版本不支持某选项时记录工具缺口，不能静默删选项后宣称等价。子模块、稀疏检出、LFS 和外部 worktree 需要明确清单；不自动 fetch 或初始化子模块。

#### 4.3.3 逐字段变更预览

| 对象 | 迁移前来源 | 迁移后目标 | 必须保持/重新审核 |
|---|---|---|---|
| Pi 入口 | 原兼容解析器与实际绑定 | 显式 runtime + local 机器定位 | 完整入口链和参数另核验 |
| 模型/思考 | 已有效授权的 Step/high 精确值 | 已登记 profile 中等价值 | 不猜 provider、不去型号后缀、不降低 thinking |
| 固定命令参数 | 旧 command 的非定位部分 | runtime 语义参数 | 不把整个 command 当机器噪声删除 |
| 凭据 | 既有 CLI/凭据系统 | 仅引用/变量名 | 不复制、打印、内联密钥 |
| 本机位置 | 获准路径值 | 02 local 白名单 | local 不得修改权限/模型/信任 |
| 任务插件 | 未显式启用 | 按审核列出的精确 ID/version/锁 | 不因目录存在自动启用 |
| 历史合同/attempt | 原字节与 schema | 保持原文件；由旧分支读取 | 不回填 v2 字段、不重编号 |
| 原生新入口 | 待部署代码 | 已批准的精确候选 | 切换不改变旧入口历史语义 |
| 规则和技能 | 当前生效基线和唯一源 | 本阶段明确变更与生成副本 | 用户授权及正式基线要求不变 |

预览为每个目标给出 `before_ref/after_ref`、所有者、理由、校验器、是否新增/替换、前置条件和补偿。不存在用 null 明确表示，与“存在但空文件”区分。敏感配置只展示安全字段差分；低熵秘密不通过普通 SHA-256 放进公开清单。

兼容读取必须显式按 v1/v2 分派。不能靠删除 `schema_version` 或 v2 字段走旧分支；来源链表明是新版草稿/发布物时，即使手改标签也拒绝降级。[^P02][^P03][^P04]

#### 4.3.4 备份不是一条 copy 命令

| 资产 | 备份/核验策略 | 易遗漏部分 |
|---|---|---|
| Git 历史 | 已批准的 bundle/对象保留方案，记录 refs 和可恢复性 | 工作区、index、配置不是 bundle 的完整备份 |
| 用户文件 | 按明确范围保留原字节、路径、类型、必要权限 | 未跟踪、忽略文件、链接、子模块工作 |
| 历史运行/审核/接受 | 不可变对象与索引、高水位分开记录 | 只存 brief 无法重建权威事实 |
| SQLite 等状态账本 | 受支持的快照/备份接口，记录应用版本与高水位 | WAL、跨账本一致性、备份后发生的撤销/费用 |
| 凭据 | 保持在原凭据系统，用版本引用与恢复说明 | 不能顺手复制进迁移包 |
| 规则技能 | 源清单、生成器、派生清单与实际基线 | 只备份生成副本失去唯一来源 |

Git bundle 主要保存所选引用及其可达对象，不能替代 index、工作树与本地配置的单独保存；linked worktree 与主仓库共享部分元数据，也不是隔离备份。迁移必须依据实际资产边界制定恢复清单。[^W07][^W08]

若实际生产选择 SQLite，使用其支持的备份方法获得一致数据库快照；运行中的 WAL 数据库不能仅复制主 `.sqlite` 文件。WAL 包含持久状态，脱离 WAL 可能丢失已提交事务。备份 API 只解决相应数据库快照，不自动与外部证据文件或另一个账本形成同一事务。[^W09][^W10]

因此冻结新派遣后，仍须协调证据写者、授权/撤销、预算迟到回报和索引生产者。可用受信快照屏障或明确高水位/追补协议；没有该能力时说明“不保证跨存储同一时点”，不能直接宣称 RPO=0。在线费用和已在途请求不受本地暂停完全控制。

**历史哈希语义**：本版可只读计算迁移前后的核验摘要并写入新的 IntegrityReport；绝不替换原文件、原摘要字段或原算法，也不把新核验摘要冒充当年的证明。这与原文“不重算历史哈希”的迁移约束分别指向“只读检查”与“改写历史”，并不冲突。

备份副本必须在隔离位置做恢复读验、成员核验、关键账本查询与旧入口读取验证。数据库 `integrity_check` 不等于业务外键/撤销高水位/预算正确，也不代替原应用不变量。[^W11]

#### 4.3.5 迁移状态机与每阶段出口

| 状态 | 必需前提 | 允许变化 | 离开条件 |
|---|---|---|---|
| DISCOVERED | 现场来源确定 | 只读报告 | 问题分类完成 |
| PREFLIGHTED | 核心未知/冲突已解决 | 只生成预览 | before 引用完整 |
| BACKUP_VERIFIED | 获准备份范围与目标 | 备份与演练记录 | 恢复读验及高水位核对 |
| PLAN_REVIEWED | 固定计划、范围、资源与审核 | 不变计划/独立审核 | 当前授权仍覆盖 |
| DRAINING | 已阻止新派遣 | 采集、对账、受审清理 | 冲突运行确已结束或被可靠隔离 |
| STAGED | 入口/schema/资源已准备且验证 | 新版本旁路对象；不启用 | 资源与计划精确一致 |
| SWITCHED | 当前 before、代际、规则与授权仍匹配 | 单次选择切换 | 登记回执可核对 |
| VERIFYING | 新选择可读 | 离线 smoke、历史核验、范围检查 | 必需 smoke 满足；真实调用单独授权 |
| ACCEPTED | 验证与主模型内容审阅完成 | 允许范围登记 | 仍不自动提交/发布 |
| HOLD / FAILED | 冲突、未知、证据不全 | 保留现场，停止新派遣 | 取得明确恢复决定 |
| ROLLING_BACK / ROLLED_BACK | 补偿审核及当前条件匹配 | 选择回退和必要补偿 | 用户工作/历史未损、新版记录保留 |

状态存储与应用副作用不是天然原子操作。STAGED 不等于 SWITCHED；回执写成功不意味着进程已启动；SMOKE PASS 不等于真实异构能力已经验证。未知的转换必须形成显式记录。

#### 4.3.6 幂等操作与受控切换

每次逻辑操作使用稳定 `operation_id`，指纹绑定迁移 ID、计划摘要、repo、before/after 资源、expected generation 和操作种类。重试同键同请求仅返回原事实；同键不同请求拒绝。新的迁移必须重新检查当前现场，不因为旧文件名相同复用许可。查询旧回执仍须当前主体具有读取权限；幂等键不是跨主体读取凭据。

建议支持“不可变配置版本 + 受控当前选择”的兼容加载路径。只有实际加载器已实现并接入 02/03/07 的核对时，才能采用单一选择指针；**本文不能假装当前源码已读取这个指针**。旧实现必须覆盖固定配置文件时，需要停写屏障、逐文件事务日志和精确 preimage/postimage 验证，不得把两次 rename 当原子多文件提交。

事务设计示意：

```text
BEGIN 权威写事务
  验证操作幂等键；存在则只读返回历史回执和当前有效性
  读取当前选择/代际，精确比较 expected
  校验当前审核、撤销、maintenance owner、活动任务与预算守卫
  将选择更新为 after；generation 单调增加
  写操作回执和待通知事件
COMMIT
返回原操作事实；响应丢失按同键查询，不再次切换
```

本地 SQLite 参考使用 `BEGIN IMMEDIATE` 串行化该合成选择更新。官方说明它会尝试立即开始写事务，存在其他写者时可能返回 BUSY；实现须有限重试整个幂等事务，而不是脱离事务重做外部副作用。[^W12]

“从 A 改 B 再改回 A”是新操作和新代际，不复活旧审核。回退后的旧 `apply` 响应重放只能报告“当时已应用、现在不是当前选择”，不能再把选择改回 B。附录覆盖这些本地账本状态，但不实现生产授权或外部文件切换。

#### 4.3.7 崩溃窗口与补偿

| 故障点 | 可确认事实 | 恢复动作 |
|---|---|---|
| 预览生成中断 | 尚无有效计划 | 废弃不完整预览，不改现行配置 |
| 备份写入中断 | 部分副本 | 标不完整，不能进入 PLAN_REVIEWED 的可执行阶段 |
| STAGED 对象完成、索引未登记 | 候选孤儿可能存在 | 重验原字节后补登记；不自动激活 |
| CAS 提交前失败 | 原选择应保持 | 同键重试前核实状态 |
| CAS 提交后响应丢失 | 原操作已登记 | 查回执与当前状态；不重复注册插件/发布合同 |
| 部分固定路径替换后失败 | 可能混合版本 | HOLD；按已记录 pre/postimage逐项恢复，不对外派遣 |
| 新进程启动记录缺失 | START_UNKNOWN | 05 核对身份和监督范围，禁止盲重发 |
| 回退前用户改了目标 | 当前值不同于本次 postimage | 停止自动回退，保留双方内容并升级 |
| 恢复旧账本缺少新撤销/费用 | 不能证明当前许可与额度 | 恢复隔离，追补高水位；不能使用旧“余额”运行 |

重试许可由 03/07 和明确维护授权决定；`retryable=true` 不自动发起模型、文件覆盖或版本切换。

#### 4.3.8 规则、技能与保护路径的最终一致性

`.agents/skills/` 继续是唯一源；`.claude/skills/` 由原同步器生成。适配能力落地时同步其相关源规范和副本，12 只检查遗漏；不能将所有规则修订留到最后。[^P12]

实施时对每项记录：源相对路径/摘要、生成器候选/版本、生成选项、派生路径/摘要、实际执行基线和批准来源。生成器可以有规范化转换，所以“源与副本一致”不必意味着两文件字节相等，应是固定规则下的可复算派生关系。发现人工修改副本时先报告差异和所有权，不未经确认覆盖用户定制。

原文提供的同步入口为 `bash scripts/dispatch-pi.sh sync-adapters`，无 Bash 时为 `python scripts/pi_dispatch.py sync-adapters`；它们在本次未执行，实施前仍需核验入口和写入范围。[^P08][^P09]

保护路径注册必须包含新可信核心、配置/审核/锁管理及规则入口，且在首次新能力派遣前生效。已写入工作区但未获提交授权、未进入实际规则基线的 AGENTS 不能当成后续执行器的新权限来源。

#### 4.3.9 启用后的观察与退出条件

首次启用限定已审 scope，不自动扩大到全部工作流或 CLI。离线 smoke 与真实调用分开；真实验证沿用原 request 预算根，不能借“健康检查”无限重试。启用后检查审核漂移拒绝、旧合同读取、项目恢复、费用未知、Observer 关闭和异常停止。

满足承诺范围的证据后记录主模型接受；仍未满足的平台/角色保持明确禁用或受限。性能下降、记录损坏、错模型、授权旁路或历史字节变化应触发停止新派遣及事故处理，不继续运行以收集更多“成功率”。

## 8. 兼容与恢复

**原文保留**

保留旧入口与旧数据读取器；阶段性回退只改变新运行选择，不改变已发生记录。
退回旧版无法解释的新项目状态时保留文件并给出不支持提示，不删除或降格记录。
配置/schema 迁移保留可核对的原版本；恢复前检查没有仍在运行的冲突进程。
真实协议能力不足或缺平台环境时交付部分结果和缺口，不以减少门禁补齐完成度。

**审阅补充**

### 8.1 恢复决策树

```text
发现异常
 ├─ 有新派遣风险 → 先停止新准入，保留采集/对账/授权清理
 ├─ 有START_UNKNOWN或进程身份未知 → 05核对，禁止盲重跑/盲杀
 ├─ 仅投影损坏 → 10从可信来源重建，不改源证据
 ├─ 切换已提交但响应丢失 → 查询原operation及当前选择
 ├─ 需要回退入口/配置 → 审核补偿、比较当前postimage与代际
 │    ├─ 已被用户/后续操作修改 → HOLD，保留双方，人工决定
 │    └─ 精确匹配 → 新operation切回获准版本，代际增加
 └─ 需要恢复数据库/文件备份 → 隔离恢复，核对高水位、撤销、费用和新证据
```

只有当前值与本次应用后的 postimage、当前代际和所有权都匹配，才可应用 inverse。旧 preimage 缺失时不能从自然语言摘要重新构造原配置。没有明确 rollback 许可或旧 profile 不再被授权时，停在 HOLD，不自动选择另一模型。

### 8.2 十步值守恢复流程

| 步骤 | 操作 | 成功判据 |
|---|---|---|
| R01 | 固定事故/迁移/operation与当前scope | 能唯一定位受影响对象 |
| R02 | 停止相关新派遣 | 所有实际入口均受控，非仅UI显示暂停 |
| R03 | 保留原日志、回执、配置和用户现场 | 无覆盖/删除，字节可核验 |
| R04 | 核实进程身份与监督范围 | 不确定项明确保留，未误杀复用PID |
| R05 | 查询权威账本而非只读brief | 判明未提交、已提交、启动未知 |
| R06 | 检查恢复许可、scope及backup | 备份完整、版本可读、当前权威来源可追补 |
| R07 | 比较目标当前值与postimage | 没有用户/后继变更；有冲突则停 |
| R08 | 执行受审补偿或隔离恢复 | 新回执、单调代际，失败历史保留 |
| R09 | 核验旧入口/模型/历史和新记录 | v1正确读取、v2未删除、用户工作不丢 |
| R10 | 新会话复核并决定恢复范围 | 明确仍未验/未知项，预算/撤销当前有效 |

R04、R06 或 R07 不满足时不得跳过。恢复期限、联系人和可授权动作由真实运维合同填写，本版不编造现有 SLA 或人员名单。

### 8.3 选择回退与数据库恢复必须分开

**选择回退**：改变未来调用的入口/profile，并保留全部新运行、审核、预算和项目记录。这是优先方式，但仍要保证旧入口不误读/写新版对象。

**数据库恢复**：可能丢弃备份时间之后的事实，风险更高。恢复到独立位置，校验记录完整性，补齐备份之后的撤销、接受替代、预算、运行与绑定版本，再决定是否切换；不能直接覆盖正在服务的账本，更不能恢复旧余额后重试收费请求。

**文件恢复**：只对明确记录了 before/after 的迁移目标进行；用户工作、历史 `.agent/runs/` 与未纳入变更清单的文件不在可覆盖范围。全仓库 `git reset --hard`、`git clean`、统一删除 `.agent`、`git add -A` 都不是本模块标准恢复动作。

### 8.4 历史完整性复核

至少比较迁移前保存的历史路径集合、文件类型、原字节摘要与既有摘要字段；新增运行可进入独立已批准新增集合，不能因为“允许新增”而允许更改旧文件。分开报告 `missing / changed / unplanned_added / unreadable`。

历史读取必须保持旧错误和 unknown：某旧 attempt 没有 provider 模型字段，不回填当前请求模型；没有费用不补零；没有 request 映射不按标题相似度自动合并。检查过程生成的新 IntegrityReport 放在新维护记录区。

### 8.5 参考账本只读排查 SQL

下列 SQL **只针对附录的合成 SelectionLedger**，不是目标项目现有表结构。生产手册应先绑定真实迁移版本，再给出对应查询：

```sql
SELECT generation, target FROM selection WHERE id = 1;
SELECT operation_id, from_generation, to_generation,
       before_hash, after_hash, plan_hash
FROM operations ORDER BY to_generation;
SELECT to_generation, COUNT(*) AS n
FROM operations GROUP BY to_generation HAVING COUNT(*) > 1;
PRAGMA integrity_check;
PRAGMA foreign_key_check;
```

重复代际查询应为空；完整性检查应返回 `ok`；外键检查应无违规。但参考表没有生产授权、进程、费用和资源闭包，这些结果绝不证明生产迁移安全。查询完成也不能自动触发恢复或续跑。

### 8.6 交付后发现问题

追加新的撤回/受限结论，并通过 03/10 传播当前影响；保留当时交付决定。报告引用缺失可恢复可信原字节，但重新渲染、重算并替换旧证据不是合法修复。例外期限届满或 CLI 自动升级时重新评估相应支持行，不能永久沿用一次成功。

"""Module 12 offline reference, NOT a production migration/authorization service.

Only caller-supplied immutable bytes and a disposable SQLite selection ledger are
used. Receipt/requirement/verified-ref inputs must come from a trusted collector in
production; this module does not authenticate them or launch processes.
"""
from __future__ import annotations

from dataclasses import dataclass
import hashlib
import json
from pathlib import Path
import re
import sqlite3
import unicodedata
from typing import Any

MAX_BYTES = 1_048_576
MAX_DEPTH = 64
MAX_INT = 9_007_199_254_740_991
HEX64 = re.compile(r"[0-9a-f]{64}\Z")
SAFE_ID = re.compile(r"[a-z0-9][a-z0-9._:-]{0,127}\Z")
STATES = {"PASS", "FAIL", "ERROR", "NOT_RUN", "SKIPPED", "CANCELLED", "INCOMPLETE", "WAIVED"}
KINDS = {"offline", "native", "real_cli", "inspection", "drill"}
REQUIRED_GUARDS = {"authorized", "quiescent", "backup_verified", "rules_current", "inputs_current"}


class ContractError(ValueError):
    def __init__(self, code: str):
        self.code = code
        super().__init__(code)  # Never echo source text or credential values.


def fail(code: str) -> None:
    raise ContractError(code)


def digest(data: bytes) -> str:
    if not isinstance(data, bytes):
        fail("E_BYTES")
    return hashlib.sha256(data).hexdigest()


def check_value(value: Any, depth: int = 0) -> None:
    if depth > MAX_DEPTH:
        fail("E_DEPTH")
    if value is None or type(value) is bool:
        return
    if type(value) is int:
        if abs(value) > MAX_INT:
            fail("E_INTEGER")
    elif type(value) is str:
        if any(0xD800 <= ord(c) <= 0xDFFF for c in value):
            fail("E_UNICODE")
    elif type(value) is list:
        for item in value:
            check_value(item, depth + 1)
    elif type(value) is dict:
        for key, item in value.items():
            if type(key) is not str:
                fail("E_KEY")
            check_value(key, depth + 1)
            check_value(item, depth + 1)
    else:
        fail("E_VALUE_TYPE")  # This limited reference accepts no JSON floats.


def canonical(value: Any) -> bytes:
    check_value(value)
    data = (json.dumps(value, ensure_ascii=False, sort_keys=True,
                       separators=(",", ":"), allow_nan=False) + "\n").encode("utf-8")
    if len(data) > MAX_BYTES:
        fail("E_SIZE")
    return data


def strict_json(data: bytes) -> Any:
    if not isinstance(data, bytes):
        fail("E_BYTES")
    if len(data) > MAX_BYTES:
        fail("E_SIZE")
    if data.startswith(b"\xef\xbb\xbf"):
        fail("E_BOM")
    try:
        text = data.decode("utf-8", errors="strict")
    except UnicodeDecodeError:
        fail("E_ENCODING")
    # Depth precheck ignores brackets in strings and respects escaped quotes.
    depth = 0
    quoted = escaped = False
    for char in text:
        if quoted:
            if escaped:
                escaped = False
            elif char == "\\":
                escaped = True
            elif char == '"':
                quoted = False
        elif char == '"':
            quoted = True
        elif char in "[{":
            depth += 1
            if depth > MAX_DEPTH:
                fail("E_DEPTH")
        elif char in "]}":
            depth -= 1

    def pairs(items):
        result = {}
        for key, value in items:
            if key in result:
                fail("E_DUPLICATE_KEY")
            result[key] = value
        return result

    def reject_number(_value):
        fail("E_NUMBER")

    try:
        value = json.loads(text, object_pairs_hook=pairs,
                           parse_constant=reject_number, parse_float=reject_number)
    except (json.JSONDecodeError, RecursionError, ValueError) as exc:
        if isinstance(exc, ContractError):
            raise
        fail("E_JSON")
    check_value(value)
    return value


def exact(obj: Any, fields: set[str], code: str = "E_FIELDS") -> None:
    if type(obj) is not dict or set(obj) != fields:
        fail(code)


def safe_path(path: str) -> str:
    if type(path) is not str or not path or len(path) > 1024:
        fail("E_PATH")
    if any(ord(c) < 32 for c in path) or any(c in path for c in "\\:*?<>|\""):
        fail("E_PATH")
    parts = path.split("/")
    reserved = {"CON", "PRN", "AUX", "NUL"} | {f"{p}{n}" for p in ("COM", "LPT") for n in range(1, 10)}
    for part in parts:
        if part in {"", ".", ".."} or part.endswith((" ", ".")) or part.split(".")[0].upper() in reserved:
            fail("E_PATH")
    return path  # Validation never rewrites original paths.


def validate_ref(ref: dict) -> None:
    exact(ref, {"kind", "id", "sha256", "path"}, "E_REF_FIELDS")
    if type(ref["kind"]) is not str or not re.fullmatch(r"[a-z][a-z0-9-]{0,63}", ref["kind"]):
        fail("E_REF_KIND")
    if type(ref["id"]) is not str or not SAFE_ID.fullmatch(ref["id"]):
        fail("E_REF_ID")
    if type(ref["sha256"]) is not str or not HEX64.fullmatch(ref["sha256"]):
        fail("E_HASH")
    safe_path(ref["path"])


def make_ref(kind: str, ident: str, path: str, payload: bytes) -> dict:
    result = {"kind": kind, "id": ident, "path": path, "sha256": digest(payload)}
    validate_ref(result)
    return result


def ref_key(ref: dict) -> tuple:
    validate_ref(ref)
    return tuple(ref[k] for k in ("kind", "id", "sha256", "path"))


def verify_manifest(manifest: dict, expected: list[dict], blobs: dict[str, bytes]) -> set[tuple]:
    """Validate an in-memory bundle, not a secure filesystem/archive extractor."""
    exact(manifest, {"schema_version", "record_type", "bundle_id", "entries"})
    if type(manifest["schema_version"]) is not int or manifest["schema_version"] != 1 or manifest["record_type"] != "evidence-manifest":
        fail("E_SCHEMA")
    if not isinstance(manifest["bundle_id"], str) or not SAFE_ID.fullmatch(manifest["bundle_id"]):
        fail("E_ID")
    if type(manifest["entries"]) is not list or not manifest["entries"] or len(manifest["entries"]) > 10000:
        fail("E_ENTRIES")
    expected_map = {}
    for ref in expected:
        validate_ref(ref)
        if ref["path"] in expected_map:
            fail("E_EXPECTED_DUPLICATE")
        expected_map[ref["path"]] = ref
    seen = set()
    folded = set()
    total = 0
    verified = set()
    for entry in manifest["entries"]:
        exact(entry, {"ref", "size"})
        ref = entry["ref"]
        validate_ref(ref)
        path = ref["path"]
        collision_key = unicodedata.normalize("NFC", path).casefold()
        if path in seen or collision_key in folded:
            fail("E_PATH_COLLISION")
        seen.add(path)
        folded.add(collision_key)
        if expected_map.get(path) != ref:
            fail("E_MEMBERSHIP")
        if type(entry["size"]) is not int or entry["size"] < 0 or entry["size"] > MAX_BYTES:
            fail("E_SIZE")
        payload = blobs.get(path)
        if not isinstance(payload, bytes):
            fail("E_RESOURCE_MISSING")
        if len(payload) != entry["size"] or digest(payload) != ref["sha256"]:
            fail("E_RESOURCE_HASH")
        total += len(payload)
        if total > 16 * MAX_BYTES:
            fail("E_BUNDLE_SIZE")
        verified.add(ref_key(ref))
    if seen != set(expected_map) or seen != set(blobs):
        fail("E_MEMBERSHIP")
    if [e["ref"]["path"] for e in manifest["entries"]] != sorted(seen):
        fail("E_ORDER")
    return verified

class CollectorReceipt:
    """Trusted input seam, no authentication implemented by this reference."""
    observation_hash: str
    kind: str
    origin: str
    native: bool
    platform: str
    cli_families: tuple[str, ...]
    environment_hash: str


def evaluate(catalog: dict, records: list[dict], selected: dict[str, str | None],
             receipts: dict[str, CollectorReceipt], verified: set[tuple],
             resolved_failures: set[str] | None = None) -> dict:

    exact(catalog, {"schema_version", "record_type", "catalog_id", "cases"})
    if type(catalog["schema_version"]) is not int or catalog["schema_version"] != 1 or catalog["record_type"] != "check-catalog":
        fail("E_SCHEMA")
    if type(catalog["cases"]) is not list or not catalog["cases"]:
        fail("E_EMPTY_CATALOG")
    cases = {}
    for case in catalog["cases"]:
        exact(case, {"case_id", "requirement_id", "required", "target_sha256", "environment_sha256", "accepted_kinds", "native_required", "platform", "heterogeneous_required"})
        if type(case["required"]) is not bool or type(case["native_required"]) is not bool or type(case["heterogeneous_required"]) is not bool:
            fail("E_BOOLEAN")
        for field in ("target_sha256", "environment_sha256"):
            if type(case[field]) is not str or not HEX64.fullmatch(case[field]):
                fail("E_HASH")
        if not isinstance(case["case_id"], str) or not SAFE_ID.fullmatch(case["case_id"]):
            fail("E_CASE")
        if case["case_id"] in cases:
            fail("E_CASE_DUPLICATE")
        if case["platform"] not in {"linux", "macos", "windows"}:
            fail("E_PLATFORM")
        if not case["accepted_kinds"] or not set(case["accepted_kinds"]) <= KINDS:
            fail("E_KIND")
        cases[case["case_id"]] = case
    if not any(c["required"] for c in cases.values()):
        fail("E_EMPTY_REQUIRED")
    if set(selected) != set(cases):
        fail("E_SELECTION_COVERAGE")
    by_id = {}
    for record in records:
        exact(record, {"record_id", "case_id", "target_sha256", "kind", "outcome", "evidence_refs"})
        if record["case_id"] not in cases or record["outcome"] not in STATES or record["kind"] not in KINDS:
            fail("E_RECORD")
        rid = record["record_id"]
        if not isinstance(rid, str) or not SAFE_ID.fullmatch(rid):
            fail("E_ID")
        if rid in by_id and by_id[rid] != record:
            fail("E_RECORD_CONFLICT")
        by_id[rid] = record
    results = []
    resolved_failures = resolved_failures or set()
    for case_id, case in sorted(cases.items()):
        record = by_id.get(selected[case_id])
        state = "NOT_RUN"
        if record is not None:
            if record["case_id"] != case_id:
                fail("E_SELECTION_TARGET")
            receipt = receipts.get(record["record_id"])
            if record["target_sha256"] != case["target_sha256"]:
                state = "STALE"
            elif receipt is None or receipt.observation_hash != digest(canonical(record)):
                state = "UNVERIFIED_SOURCE"
            elif receipt.environment_hash != case["environment_sha256"] or receipt.platform != case["platform"]:
                state = "STALE_ENVIRONMENT"
            elif receipt.kind != record["kind"] or receipt.kind not in case["accepted_kinds"]:
                state = "INSUFFICIENT_EVIDENCE"
            elif receipt.origin not in {"synthetic", "captured"}:
                state = "UNVERIFIED_SOURCE"
            elif (case["native_required"] or record["kind"] == "real_cli") and receipt.origin != "captured":
                state = "INSUFFICIENT_EVIDENCE"
            elif case["native_required"] and not receipt.native:
                state = "INSUFFICIENT_EVIDENCE"
            elif case["heterogeneous_required"] and (record["kind"] != "real_cli" or len(set(receipt.cli_families)) < 2):
                state = "INSUFFICIENT_EVIDENCE"
            elif not record["evidence_refs"] or any(ref_key(ref) not in verified for ref in record["evidence_refs"]):
                state = "INCOMPLETE"
            else:
                state = record["outcome"]
                if state == "SKIPPED":
                    state = "NOT_RUN"
                prior_failed = {r["record_id"] for r in by_id.values()
                                if r["case_id"] == case_id and r["record_id"] != record["record_id"]
                                and r["outcome"] in {"FAIL", "ERROR"}}
                if state == "PASS" and not prior_failed <= resolved_failures:
                    state = "UNRESOLVED_FAILURE"
        elif selected[case_id] is not None:
            state = "INCOMPLETE"
        results.append({"case_id": case_id, "requirement_id": case["requirement_id"],
                        "required": case["required"], "effective_status": state})
    required = [r for r in results if r["required"]]
    passed = sum(r["effective_status"] == "PASS" for r in required)
    readiness = "COMPLETE" if passed == len(required) else ("PARTIAL" if passed else "NONE")
    return {"evidence_readiness": readiness, "required_total": len(required),
            "required_passed": passed, "can_dispatch": False, "cases": results}


def compare_inventory(before: dict[str, str], after: dict[str, str], allowed_new: set[str]) -> dict:
    """Compare verification inventories; never replace any historical hash field."""
    for inventory in (before, after):
        for path, value in inventory.items():
            safe_path(path)
            if not isinstance(value, str) or not HEX64.fullmatch(value):
                fail("E_HASH")
    missing = sorted(set(before) - set(after))
    changed = sorted(p for p in set(before) & set(after) if before[p] != after[p])
    unplanned = sorted(set(after) - set(before) - allowed_new)
    return {"unchanged": not (missing or changed or unplanned), "missing": missing,
            "changed": changed, "unplanned": unplanned}


class SelectionLedger:
    """Synthetic one-row selection CAS. No filesystem changes, process launch,
    production authorization, public CLI, or schema downgrade is implemented.
    Each caller/thread must open its own instance/connection.
    """
    def __init__(self, path: Path):
        self.db = sqlite3.connect(path, timeout=5, isolation_level=None)
        self.db.execute("PRAGMA foreign_keys=ON")
        self.db.execute("PRAGMA synchronous=FULL")
        self.db.executescript("""
        CREATE TABLE IF NOT EXISTS selection (
          id INTEGER PRIMARY KEY CHECK (id=1), generation INTEGER NOT NULL,
          target TEXT NOT NULL);
        CREATE TABLE IF NOT EXISTS operations (
          operation_id TEXT PRIMARY KEY, fingerprint TEXT NOT NULL,
          from_generation INTEGER NOT NULL, to_generation INTEGER NOT NULL,
          before_hash TEXT NOT NULL, after_hash TEXT NOT NULL, plan_hash TEXT NOT NULL);
        """)

    def initialize(self, target: str) -> None:
        if not HEX64.fullmatch(target):
            fail("E_HASH")
        self.db.execute("INSERT INTO selection VALUES(1,1,?)", (target,))

    def current(self) -> tuple[int, str]:
        row = self.db.execute("SELECT generation,target FROM selection WHERE id=1").fetchone()
        if row is None:
            fail("E_UNINITIALIZED")
        return row

    def activate(self, operation_id: str, expected_generation: int,
                 before_hash: str, after_hash: str, plan_hash: str, guards: dict,
                 *, crash_before_commit: bool = False, lose_response: bool = False) -> dict:
        if not isinstance(operation_id, str) or not SAFE_ID.fullmatch(operation_id):
            fail("E_ID")
        if type(expected_generation) is not int or not 1 <= expected_generation < MAX_INT:
            fail("E_GENERATION")
        if any(type(h) is not str or not HEX64.fullmatch(h) for h in (before_hash, after_hash, plan_hash)):
            fail("E_HASH")
        fingerprint = digest(canonical({"operation_id": operation_id,
            "generation": expected_generation, "before": before_hash,
            "after": after_hash, "plan": plan_hash}))
        self.db.execute("BEGIN IMMEDIATE")
        try:
            old = self.db.execute("SELECT fingerprint,to_generation,after_hash FROM operations WHERE operation_id=?", (operation_id,)).fetchone()
            if old:
                if old[0] != fingerprint:
                    fail("E_IDEMPOTENCY_CONFLICT")
                current = self.current()
                result = {"replayed": True, "applied_generation": old[1],
                          "applied_target": old[2], "currently_selected": current == (old[1], old[2]),
                          "current_generation": current[0], "current_target": current[1]}
            else:
                if set(guards) != REQUIRED_GUARDS or any(type(v) is not bool or not v for v in guards.values()):
                    fail("E_GUARD")
                if self.current() != (expected_generation, before_hash):
                    fail("E_CAS_CONFLICT")
                cursor = self.db.execute("UPDATE selection SET generation=generation+1,target=? WHERE id=1 AND generation=? AND target=?", (after_hash, expected_generation, before_hash))
                if cursor.rowcount != 1:
                    fail("E_CAS_CONFLICT")
                self.db.execute("INSERT INTO operations VALUES(?,?,?,?,?,?,?)", (operation_id, fingerprint, expected_generation, expected_generation+1, before_hash, after_hash, plan_hash))
                result = {"replayed": False, "applied_generation": expected_generation+1,
                          "applied_target": after_hash, "currently_selected": True,
                          "current_generation": expected_generation+1, "current_target": after_hash}
            if crash_before_commit:
                fail("E_SIMULATED_PRECOMMIT_FAILURE")
            self.db.execute("COMMIT")
        except BaseException:
            if self.db.in_transaction:
                self.db.execute("ROLLBACK")
            raise
        if lose_response:
            fail("E_SIMULATED_RESPONSE_LOSS")
        return result

    def close(self) -> None:
        self.db.close()

"""Extract explicitly named reference blocks; never execute extracted content."""
from pathlib import Path
import argparse
import re

PATTERN = re.compile(r'<!-- artifact-file: ([^\r\n]+) -->\n```[^\n]*\n(.*?)\n```', re.S)

def extract(document: Path, output: Path) -> int:
    if output.exists():
        raise ValueError('Output directory must not exist; choose a new directory.')
    text=document.read_bytes().decode('utf-8')
    blocks=PATTERN.findall(text)
    if not blocks:raise ValueError('No named blocks found.')
    names=set()
    for name,body in blocks:
        parts=name.split('/')
        if (not name or any(p in {'','.','..'} for p in parts)
                or any(c in name for c in '\\:*?<>|\"')
                or any(ord(c)<32 for c in name) or name in names):
            raise ValueError('Unsafe or duplicated block name.')
        names.add(name)
    output.mkdir(parents=True,exist_ok=False)
    for name,body in blocks:
        path=output/name;path.parent.mkdir(parents=True,exist_ok=True)
        path.write_bytes((body+'\n').encode('utf-8'))
    return len(blocks)
