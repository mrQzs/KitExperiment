## 1. 目标与非目标

### 1.1 原文目标与完成定义

让主会话在恢复或切换上下文后，从持久记录取得当前目标、决定、进度、阻塞和下一动作。进度事实由调度器登记，能够回查原始证据；简报帮助阅读，**不成为验收、授权或派遣依据**。在关键检查点生成带来源和版本的确定性简报，减少反复打开大型日志的操作。[^P10]

本模块包含项目生命周期索引、状态投影、版本化决定、确定性简报、读取记录，以及按 `request_id` 展示可观测用量。不包含常驻模型进程、任意聊天历史自动理解、自动批准或派遣。不承诺文件写入会唤醒主会话，不承诺主模型理解所有规则，不把模型自述、摘要完整或退出码 0 当成任务验收。可选 Observer 关闭后，以上确定性能力仍须可用。

建议完成定义：删除可重建投影后，能够从固定来源和相关确认记录恢复相同的业务事实；事件缺口、来源损坏、冲突、未知费用和失效审核明确可见；新会话能分辨“待审、已验收、已集成、已替代”，且没有因读取简报触发任何新业务动作。

“恢复相同业务事实”不等于恢复不存在的证据。若决定确认回执、请求映射或授权来源从未持久化，应报告无法重建相应部分，而不是让模型根据摘要补全。

### 1.2 审阅发现与优先补强项

| 原文尚需展开的点 | 直接实现时容易出错的方式 | 本版处理 |
|---|---|---|
| 稳定来源 ID 未明确到变化记录 | 用同一 attempt ID 去重，吞掉后续 verdict 或 integration | 区分实体身份、来源记录身份、记录修订与索引身份 |
| 游标与业务先后未分开 | 迟到补录的旧批准覆盖较新撤销 | 索引按登记顺序，业务按来源版本/因果链归约 |
| 单写者与去重没有提交边界 | 日志成功、去重表失败后重复追加 | JSONL 为索引提交事实；去重缓存可重建，不作第二真相源 |
| 补录扫描没有完整性判据 | 扫描返回空就当所有来源已索引 | 固定扫描范围、生产者高水位、分页与未完整列表 |
| 临时文件加替换只覆盖单文件 | `state.json` 和 `brief.md` 被读成不同版本 | 不可变视图包加一个原子指针；兼容文件仅为展示别名 |
| 重建后游标是否保持不明确 | 旧会话游标与新日志序号误匹配 | 加索引 generation，跨代读取必须 RESET |
| 当前有效性与历史事实混用 | 历史集成因审核过期被抹去，或旧 PASS 获得新权限 | 分开存历史事实、当前观察、准入守卫 |
| 简报限长未定义必须保留项 | 截断恰好丢掉停止、未知启动或授权缺口 | 安全关键项优先且不可静默截掉；放不下明确报错 |
| 读取、投递、自身刷新未解耦 | 每次记录读取又生成新 brief，产生循环 | 阅读/投递遥测与业务内容水位分离 |
| 预算有累计要求但容易二次计算 | 把多个累计快照求和 | 只读取 07 的固定账本快照，保留版本和未知覆盖 |
| 决定可版本管理但确认来源不足 | Git 提交或文件存在被当作主模型确认 | 保存受控确认回执及适用范围，不靠文字自动批准 |
| “有来源”易被误解为“语义已证实” | 真实引用支撑不了简报结论 | 来源完整性、登记可信度、语义支持分级展示 |

| 编号 | 不变量 |

| I04 | 索引游标只说明登记顺序，不替代业务修订顺序、Git 基线或授权 epoch。 |
| I05 | 执行结束、检查 PASS、主模型接受、例外接受、已集成和已替代分别表达。 |
| I06 | `state.json` 与 `brief.md` 都是派生视图；任何真实动作仍到 03/07 读取当前守卫。 |
| I07 | 来源缺失、损坏、未封存、未知版本和冲突不能回填为成功；不得静默选择较老“可用”批准。 |

| I15 | 同账户文件哈希和锁不能证明恶意同账户进程无法伪造记录；保证上限必须如实记录。 |

### 1.4 保证分层

| 级别 | 能证明的事项 | 不能据此推出 |
|---|---|---|
| 字节完整性 | 当前读到的字节与某个固定引用一致 | 来源身份可信、内容真实 |
| 受控来源登记 | 受信适配器核验了发布回执、实体及记录类型 | 业务授权仍有效、语义检查一定充分 |
| 当前状态观察 | 截至所列来源高水位和核验时点，状态如何 | 观察后没有发生变化 |
| 业务准入 | 03/07 针对具体动作复核后的独立结论 | 所有后续动作均可复用 |
| 阅读或宿主回执 | 某接口返回了字节，或某会话确认了具体版本 | 模型已理解并会严格遵守 |

事件驱动投影通常存在写入到视图更新的延迟。因此这里把观察边界显式写进状态，而不把读模型设计成权限缓存。官方事件溯源资料可用于理解这个延迟及追加纠正的思路；本模块仍以实际来源为业务事实权威，不照搬“索引就是唯一业务事件库”的前提，也不采纳宽松忽略未知授权字段的建议。[^W4]

### 2.1 原文依赖与模块职责

基础依赖 01 公共协议、03 审核与锁定、07 工作流；完整接入再消费 09 的草稿、审核及发布事件。05 提供进程/采集事实，06 提供插件锁，13 仅为可选消费者。[^P10]

### 2.2 输入对象及缺失行为

| 输入 | 最低识别/核验 | 缺失或尚未实现时 |
|---|---|---|
| 原始运行与历史转换记录 | 所属 repository/request、attempt/run、封存或提交回执 | 标记待恢复，不生成终态事实 |
| verdict / AcceptedResult | 候选、检查集、裁决类型、登记身份 | 不把检查 PASS 转成接受 |
| Integration / supersession | 原接受对象、集成引用、后继对象、来源版本 | 保留“未知是否集成” |
| 审核与当前验证观察 | approval ID、subject、输入锁、当前关系及观察版本 | 显示历史审核事实与当前未知，不继续派遣 |
| 合同发布 | 双格式文件、审核关联、发布版本、完整性 | 显示发布未完成；草稿和正式合同不混用 |
| 预算账本快照 | request、ledger ID/代际/修订、覆盖范围、币种、未知项 | 显示 UNKNOWN，不用 `cmd_metrics` 的局部小计补齐 |

| 配置/插件/环境 | 固定资源引用与当前核验观察 | 标明对应版本及过期/缺失原因 |
| 历史 request 映射 | 显式映射记录、确认来源、原记录引用 | 进入未归属历史清单，不凭标题自动归类 |

### 2.3 输出类型与只读性质

建议记录家族包括 `ProjectEvent`、`SourceScanReport`、`SourceVerificationSnapshot`、`ProjectState`、`DecisionRecord`、`ProjectViewManifest`、`BriefReadReceipt`、`DeliveryReceipt`、`RecoveryReport`。

其中生产 Schema 必须与 01 注册表协调。附录的**合成参考 profile**仅实现其中的来源夹具、项目事件、简化状态、视图 manifest 和读取回执；它不冒充 03/07/09 的生产 Schema。

`project status` 建议返回：命令是否完成、投影健康度、当前观察边界、任务状态、阻塞、预算引用和未核实范围。必须区分 `command_status=ok` 与 `project_health=degraded`；命令成功读取不代表任务全部通过。`dispatch_eligibility` 在 10 中为 `not_evaluated` 或引用 07 的历史就绪观察，不能自行设置具有准入效力的 `true`。

## 3. 现状与复用点

### 3.1 原文记载，不等于本次代码审计

| 原文位置 | 原文记载的能力 | 接入前需要补录 |
|---|---|---|
| `scripts/pi_dispatch.py::cmd_status` | 按 attempt 显示状态、检查、验收、时间和费用 | 真实字段、终态解释、文件完整性规则 |
| `cmd_metrics` | 区分 PASS 与例外接受；既有统计只覆盖 Pi 执行端 | 来源范围、去重键、累计/增量和未知值 |
| `cmd_mark` | 维护 INTEGRATED、SUPERSEDED，保留集成引用和原因 | 是否有不可变转换历史、记录身份与并发条件 |
| `cmd_wait`、收集恢复 | 原始执行结束与恢复事实 | 退出、EOF、封存与清理如何区分 |
| 候选快照与 verdict | 固定候选及验收证据 | 候选、检查、接受和集成的精确引用 |
| `summary.md` | 历史 attempt 的阅读入口 | 摘要对应哪个版本，定位原始小段证据的方法 |

原文指出缺少跨任务依赖投影、版本化决定索引和恢复 brief。不能因为本版包含参考代码，就声称这些缺口已经在用户项目中修复。[^P10]

### 3.2 复用原则

保留旧 attempt 状态名、原始证据路径与 v1 的语义。项目层可以增加标签，但应保留原值，例如 `legacy_attempt_status`、`verdict_kind`、`acceptance_relation`、`integration_relation`，不把全部状态压缩成一个新的 `DONE`。

阅读历史时先看 `summary.md` 以决定需要打开哪些证据；真正核对时读取固定源文件和最小必要片段。摘要缺失可以降低阅读便利性，不能把真实存在的原始证据当成不存在；反之只有摘要而缺正式证据时，不推定原验收成立。

## 4. 接口和行为约束

### 4.1 存储与来源

#### 4.1.1 目录、所有者与恢复分类

原路径保持：`.agent/project/overview.md`、`decisions/`、`events.jsonl`、`state.json`、`brief.md`、`observer/`。建议扩展如下，新增布局须由正式合同采纳：

```text
.agent/project/
  overview.md                         # 主模型确认后的可读当前概览
  decisions/<decision-id>/vN.json      # 不可变决定内容
  confirmations/                      # 概览/决定确认回执；不能仅靠 Git 历史替代
  events.jsonl                        # 当前代索引；单写者追加
  index-generation.json               # 索引身份、来源空间及受控恢复关联
  writer.lock                         # 稳定锁文件，正常解锁后不删除
  state.json                          # 兼容展示投影，不是业务准入来源
  brief.md                            # 兼容展示简报，不保证与上一文件成对原子更新
  current.json                        # 唯一当前视图包指针
  views/<view-id>/
    state.json
    brief.md
    manifest.json                     # 引用前两份完整字节，不含自身哈希
  scans/                              # 扫描高水位、分页和完整性报告
  verifications/                      # 来源核验观察及范围
  reads/                              # 读取回执；与业务内容刷新水位分开
  deliveries/                         # 宿主投递记录；不存在接口时可为空
  diagnostics/                        # 冲突、缺口、恢复待决；不改写原记录
  recovery/                           # 修复计划、CAS 输入及结果
  quarantine/                         # 损坏索引副本/尾部，不当正式来源
  observer/                           # 可选建议，不混入已确认事实
```

| 类型 | 是否可删除后直接重建 | 备份/保留重点 |
|---|---|---|
| state、brief、确定性视图 manifest | 来源、规则和版本完整时可重建 | 保留被读取回执引用的旧版本，直至保留策略允许回收 |
| 生命周期索引 | 原始来源和来源身份/版本信息完整时可重建 | 原游标顺序可能无法恢复，必须处理 generation |
| 原始运行、verdict、授权、接受、集成事实 | 不能从 brief 反向重建 | 遵循所属模块不可变证据策略 |
| 目标/决定内容及确认回执 | 未必可从 attempt 重建 | 必须进入明确备份，必要时允许版本管理 |
| request 映射与恢复授权记录 | 不能通过语义相似度重造 | 原映射与后续纠正都保留 |
| 扫描/核验报告 | 某次历史观察不能用今天的检查冒充 | 新检查生成新观察 |
| 读取/投递记录 | 不能根据文件存在反推 | 按审计保留策略保存；不是完成/费用事件 |

`.gitignore` 只控制 Git 跟踪，不是备份、安全控制或保留策略。不要用一个过宽 `.agent/project/**` 规则意外屏蔽需要保留的决定/确认，也不要把读取会话标识和敏感预算默认提交。实际忽略规则需与现有 `.agent/` 规则逐层核对，不在本文擅自覆盖。单纯版本管理 `overview.md` 也不能补足当时谁确认了哪份内容的来源。

#### 4.1.2 公共引用、身份与版本

`ResourceRef={kind,id,sha256}`，文件资源另有仓库相对正斜杠 `path`。哈希针对实际固定的完整字节；原 Markdown、JSON 来源和二进制内容在核验时不重新格式化。文件不写自己的哈希，不构造“brief → manifest → brief”的循环依赖。[^P01]

本版新生成的合成 JSON 文件显式采用 01 的确定性写出表达式，标记独立序列化 profile；**这不把任意外部 JSON 升级为可规范化重算的对象**。同内容不同换行的原文件仍有不同字节哈希。

| 身份/版本 | 建议作用域与含义 | 禁止混用 |
|---|---|---|
| `repository_namespace` | 管理体系分配的仓库身份，不从绝对路径生成 | 路径相同不证明同一仓库；clone/迁移需显式映射 |
| `project_id` | 本仓库中项目状态索引范围 | 不代替预算根 |
| `request_id` | 01/07 的累计预算根 | 不因恢复、重规划或读取重置 |
| `task_id` | request 内任务；联合键包含 request | 相同标题不能合并 |
| `plan_version`、attempt、run | 分别引用合同、尝试、调用 | attempt 终态不能覆盖整个任务版本链 |
| `source_record_id` | 生产者已提交的不可变事实记录 | 不能直接用可变 attempt 容器 ID 充当每个转换 ID |
| `producer_revision` | 某实体某事实流的已登记修订号 | 不是事件文件行号或文件 mtime |
| `event_id` | 稳定来源事实在索引中的身份 | 重试追加不能每次生成新随机身份来绕过去重 |
| `index_generation` | 一代索引的稳定身份 | 重建序号不能假装仍属于旧代 |
| `cursor.seq` | 当前代连续有效登记序号 | 不是所有生产者事实的全局因果时钟 |
| `reducer_profile`、`renderer_profile` | 归约、排序、措辞与截断规则版本 | 更新代码不能悄悄改变历史解释 |

生产去重键建议：

```text
SourceKey = (repository_namespace, producer_namespace,
             source_record_id, immutable_facet_id)
EntityStream = (repository_namespace, project_id, request_id,
                entity_kind, entity_id, fact_stream)
Cursor = (index_generation, seq)
```

`immutable_facet_id` 只在同一封存源记录确定性导出多个生命周期事实时使用，由版本化适配器登记，不能由模型任意取值。更换提取器后重新解释旧来源，应产生显式新视图/解释版本，不用改 facet 绕开旧来源冲突。

CloudEvents 以来源和 ID 的组合区分事件身份，这为复合去重命名空间提供参照；这里没有直接宣称实现 CloudEvents，也不导入其所有字段或容错规则。[^W5]

#### 4.1.3 ProjectEvent 字段级合同建议

| 字段 | 类型/必填 | 规则 |
|---|---|---|
| `record_type` / `schema_version` | 注册家族 / 正整数 | 新项目事件版本，不等于合同 v1/v2 |
| `repository_namespace`、`project_id` | 非空稳定 ID | 来源与目标索引须一致 |
| `event_id` | 稳定 ID，必填 | 可由带域前缀的 SourceKey 摘要生成，不把来源哈希单独当事实身份 |
| `cursor` | generation + 正整数 seq | 写者在锁内分配；拒绝同代缺口和回退 |
| `request_id` | 已确认请求或显式未归属形式 | 生产兼容入口支持未归属历史；不得伪造 request |
| `event_type` | 受信注册的生命周期类型 | 不能用厂商 JSON 的任意 type 直接透传 |
| `subject` | entity kind/id 及必要 task/attempt/run/plan 标识 | 由实际来源验证，不靠 filename 猜全部字段 |
| `producer` / `source_record_id` | 受信生产者空间及事实记录身份 | 字符串合法不等于身份已认证 |
| `source_ref` | 完整文件 ResourceRef | 必须指向已完整登记/封存对象 |
| `producer_revision` | 正整数或旧来源明确 unknown | 使用来源约定，缺失时不得造递增业务版本 |
| `predecessor_refs` / `causes` | 固定前驱记录引用数组 | 支撑替代/撤销/发布前提，不用时间戳替代 |
| `occurred_at` | 来源记录时间或明确未知 | 展示/诊断用；不作多源冲突裁决 |
| `recorded_at` | 核心登记 UTC 时间 | 不作为业务先后依据 |
| `extractor_ref` | 版本化受信提取器/规则引用 | 说明怎么从来源形成事实 |
| `payload` | 受限小字段或明确不保存 | 只是来源的可核对投影；不可携带任意代码和大段日志 |
| `recovered_from` | 可选补录扫描/恢复报告引用 | 不改变原事实发生时间 |

附录为了减小可运行示例，使用 `stream + subject_id + revision + previous_record_id` 的**封闭合成 profile**，不包含通用生产 `causes`、多事实提取器和历史 unknown 映射。不能把合成字段名直接当作已经兼容前序所有 Schema。

结构验证之外必须验证：来源授权可读、来源家族与生产者匹配、完整字节哈希、上下文身份一致、来源发布完成，以及该事实类型确实由受信适配器提取。只有 schema-valid 的 `{"approved":true}` 仍不能成为审核或接受事件。

#### 4.1.4 生命周期类型注册表建议

下面是建议的领域家族；精确字符串与 payload 需在接线合同中冻结。类型的关键性由受信注册表决定，不接受来源自行声明 `critical=false` 来降级。

| 事件家族 | 权威来源 | 对当前投影的影响 | 不能推导 |
|---|---|---|---|
| `goal.confirmed` / `overview.confirmed` | supervisor 确认回执 | 当前目标、非目标和约束版本 | 用户同意了未覆盖的执行范围 |
| `decision.proposed` | 明确标记提议的来源 | 待决清单 | 已确认决定 |
| `decision.confirmed/superseded/revoked` | 受控决定登记 | 适用范围和版本链 | 自动改变 03 的真实授权 |
| `planning.status_observed` | 09 规划记录 | REQUESTED/PLANNING/待审等状态 | 已正式发布或可执行 |
| `contract.candidate_sealed` | 09 候选封存 | 可审对象存在 | 已通过审核 |
| `contract.published` | 09 完整发布回执 | 正式版本可定位 | 当前输入与授权仍匹配 |
| `approval.registered` | 03 登记回执 | 某时审核决定存在 | 永久可运行 |
| `approval.superseded/revoked` | 03 当前关系记录 | 相关审核当前关系变化 | 过去运行未发生 |
| `approval.validation_observed` | 03 某动作检查结果 | 截至观察点的有效性/失效原因 | 通用可重用 permit |
| `attempt.prepared/started` | 既有核心/05 事实 | 运行及其基线、输入快照 | 产生候选或接受 |
| `attempt.terminal_observed` | 05/收集封存 | 主进程终态与采集/清理事实 | PASS、无后代残留或已集成 |
| `candidate.frozen` | 核心候选记录 | 固定候选 K | K 已验收 |
| `check.completed` | 独立检查记录 | 某检查对 K 的结果 | 所有检查或主模型已接受 |
| `verdict.recorded` | 既有门禁/裁决来源 | PASS/失败/例外等原值 | 与新候选 K2 相同结论 |
| `result.accepted/revoked` | 07/主模型接受记录 | 跨任务消费资格的当前观察 | 自动基线使用或集成授权 |
| `result.integrated/superseded` | 现有 mark/集成记录 | 实际集成、后继替代事实 | 自动 rebase、改 base_sha |
| `request.stopped/resumed` | 07 受控状态转换 | 是否允许新派遣的历史观察 | 已停止所有进程 |
| `budget.snapshot_observed` | 07 账本快照 | 替换对应账本观察版本 | 新增一笔消耗 |
| `source.scan/verification_observed` | 10 受控扫描/核验 | 覆盖、新鲜度和缺口 | 自动批准业务动作 |

读取、投递、渲染完成等遥测建议单独存储。确有统一索引需求时，必须设置独立的 `content_watermark`，保证这些遥测不进入决定简报正文变化的业务输入。

#### 4.1.5 去重与冲突判定表

| 输入情况 | 行为 | 是否推进业务状态 |
|---|---|---|
| 同 SourceKey、同固定引用、同提取结果 | 返回既有 event_id/cursor，标记 replay | 否 |
| 同 event_id 但 SourceKey 不同 | 身份冲突，保留两侧诊断 | 否，受影响范围阻塞 |
| 同 SourceKey、不同字节哈希 | 来源完整性冲突；旧记录不覆盖 | 否 |
| 同 SourceKey、相同哈希但位置改变 | 按合法迁移/重定位流程核验，不能默认为相同授权 | 未确认前不推进 |
| 不同 SourceKey、同实体修订和不同内容 | fork/冲突；不按最后到达选择 | 否 |
| 同一调用的累计用量在多种视图出现 | 只索引来源或账本观察，不重复记账 | 不增加费用 |
| 合法的新事实修订 | 校验前驱与来源后追加 | 按业务版本归约 |
| 旧事实迟到 | 追加一次，保留发生/登记两个时间 | 不覆盖较新当前关系 |
| 未支持 schema/type | 留诊断；关键或无法判定关键性时阻塞相关范围 | 不猜测默认值后继续 |

项目事件文件中的物理重复行属于索引格式问题，与 API 输入重复不同。新写者不应写出重复行；修复时须记录处理策略和原始副本，不能因消费端“会去重”就忽略日志损坏。

#### 4.1.6 旧记录和可变文件适配

有不可变历史转换记录时，优先按该记录的稳定 ID 登记。一个 attempt 的 `prepared`、`started`、`verdict`、`INTEGRATED` 应来自各自事实或已封存版本，不能全都使用 `attempt_id` 作为唯一去重键。

如果旧实现只有可变 `status.json`，本模块不能凭每次读到的内容哈希自行制造完整历史。应由兼容适配器生成**本次观察记录**，明确原文件、观察时点、当时字节摘要、可证明范围及历史缺失；它只能说明观察时看到的状态，不能补造当年转换时间、授权或确认者。

先核验来源发布/封存证据，再生成事件。文件存在、文件大小稳定两次、mtime 变旧都不单独证明来源已提交。生产者有数据库提交记录时使用其可比较提交位置；生产者仅用文件协议时，要先明确原子发布与完成标记的契约。不能假定添加一个 `.done` 文件就解决所有双写问题。

发现同一稳定源记录内容改变，不应改用新的内容摘要作为 source ID 把它伪装成“新合法事实”。合法修订需生产者提供新记录身份和前驱关系，原始记录仍保留。

#### 4.1.7 来源核验与扫描完整性

建议 `SourceVerificationSnapshot` 保存：固定来源集合、每项 `verified/missing/incomplete/hash_mismatch/schema_unsupported/conflict/access_denied`、验证器版本、观察时点、授权可见范围、生产者高水位及核验报告引用。不能把“无权限读取”描述成“文件不存在”。

`SourceScanReport` 至少包含：

| 字段组 | 内容 |
|---|---|
| 范围 | repository/project/request 过滤、允许的生产者、来源根/登记表引用 |
| 固定边界 | 每个生产者的起始/结束高水位或快照 token；无稳定边界时明确 `best_effort` |
| 遍历 | 页数、续页 token、已检查对象、重复项、未完整项、权限失败和读取失败 |
| 结果 | 新补录数量、已登记重复数量、冲突列表、仍未索引来源、外部来源缺口 |
| 完整性 | `complete_for_declared_cut`，只对声明的观察切面成立，不表示今后无新记录 |
| 解释版本 | 来源 adapter、legacy 映射、schema registry、扫描器版本 |

完整扫描要能回答“扫描了什么、截至哪里、哪些尚未检查”。目录遍历顺序与遍历期间新文件是否可见不能作为一致快照保证；需要生产者的稳定登记目录/提交边界，或受控暂停/栅栏方案。Python 对目录扫描期间增删对象的可见性没有统一保证。[^W1]

未取得完整性条件时，状态可以展示已知事实，但整体标记 `PARTIAL_SOURCE_COVERAGE`。尤其不能在只读取已有 events 的情况下将“没有发现撤销”解释成“审核仍有效”。

#### 4.1.8 目标、决定与规则版本

建议 `DecisionRecord` 包含 `decision_id`、`version`、`scope`、`statement`、`rationale`、`source_refs`、`confirmation_ref`、`supersedes`、`status`、`effective_from` 和明确的限制。作用域应指定 repository/request/task、适用资源/动作；不能只靠一句“适用全项目”让任意后续动作获得权限。

| 状态 | 来源要求 | 简报显示 |
|---|---|---|
| PROPOSED | 可追溯提议来源 | 提议/假设，不放进已确认规则 |
| CONFIRMED | 受控 supervisor 确认具体字节和范围 | 已确认，但业务授权仍单独核验 |
| SUPERSEDED | 新决定明确指向旧版本、同范围替代成立 | 旧版本留历史，展示当前后继 |
| REVOKED | 受控撤销记录 | 已撤销；不能退回更老版本自动生效 |
| CONFLICTED/UNVERIFIED | 并发 fork、来源缺失或未确认 | 待主模型裁决，不能按时间较晚者获胜 |

同一决定范围建议使用 head generation + expected predecessor 的 CAS；跨范围适用冲突由明确的规则或主模型解决，不通过项目索引顺序裁决业务优先级。对 overview 的修改也应绑定具体字节和确认回执，不能靠“该文件已被 Git 提交”推导其审核成立。

### 4.2 崩溃、并发与投影

#### 4.2.1 三类顺序与四种水位

必须分开：**来源发生/生效顺序、索引登记顺序、消费者应用顺序**。

```text
来源：     发布 r1 → 撤销 r2
补录：     r2 先被发现，r1 后被发现
索引：     cursor 41=r2，cursor 42=r1
当前关系：仍由 r2 决定；不能因 42 更大恢复 r1
```

建议状态同时记录：

- `indexed_cursor`：某代索引的有效前缀终点。
- `applied_cursor`：当前投影处理到的同代终点，不超过 indexed。
- `source_vector`：各生产者所覆盖的来源提交/业务修订高水位。
- `verification_cut`：本次字节、依赖和当前关系核验的固定观察集合。

事件游标连续只证明索引没有该类型的序号缺口；不证明所有来源已补录。来源 vector 已覆盖某账本版本，也不证明 03 的当前授权在稍后仍有效。时间戳用于展示和期限检查，不是多源事务总序。

#### 4.2.2 追加算法与线性化边界

首期建议继续采用原文的单写者 JSONL 索引。索引可以重建；权威业务事实仍归来源模块。可选 SQLite/其他查询缓存必须是派生缓存，不与 JSONL 并列成为两套可独立决定“已接受/已计费”的真相源。

```text
append_source(source_ref, source_key):
  1. 从受控句柄/固定对象版本读取，验证来源完整、Schema、身份、范围和字节。
  2. 获取本项目稳定的单写者锁；重新读取当前 generation 和有效日志终点。
  3. 有未完整尾部、序号缺口或未解决写入错误 → 拒绝继续追加。
  4. 用有效日志/已核验缓存查 SourceKey：
       同引用同事实 → 返回旧 event_id/cursor；不重新分配游标。
       冲突 → 持久化诊断，阻塞受影响范围；不覆盖旧记录。
  5. 在锁内分配 next_seq，形成完整 UTF-8 JSON 行，末尾一个 LF。
  6. 完整写入；处理短写；flush；按持久性配置 fsync。
  7. 更新可重建的去重/查询缓存；缓存失败不重写另一条同源事件。
  8. 返回登记回执；读者仍须核验来源和当前性。
```

正常成功回执在完整行已完成所声明同步后返回。写入/同步结果不确定时返回登记状态未知，调用者用原 SourceKey 查询/重送；不要换 ID。崩溃后可见的完整有效行即使尚未收到成功回执，也可以在核对原始来源后保留为索引事实。这里承诺的是**幂等的索引效果**，不是外部模型调用、进程启动或业务接受的全局 exactly-once。

`json.dump` 多次写入同一个文件本身不形成带边界的合法 JSON 文档序列；本索引显式定义逐行 framing。Python 默认 JSON 对重复键等输入较宽松，所以新入口需要额外严格校验，而不是仅设置输出 `allow_nan=False`。[^W2]

#### 4.2.3 单写者锁和平台边界

| 环境 | 建议实现 | 必须验证/明确限制 |
|---|---|---|
| Linux/macOS 本地盘 | 独立稳定锁文件上的内核锁，例如受控 `flock` 后端 | 超时、退出释放、同进程多描述符、rename 与锁文件 inode 保持 |
| Windows 本地盘 | 明确的文件字节区间锁后端，例如 `LockFileEx` | 独占标志、句柄/范围生命周期、失败码、共享打开方式和替换行为 |
| 网络盘/同步目录 | 首期不宣称可靠支持 | NFS/SMB、云同步冲突副本、跨主机 fencing 须另验收 |
| 多主机控制器 | 超出原文首期保证 | 不能用本机 lockfile 或 PID 文件替代分布式写者隔离 |

锁文件存在不是占用证明；PID 文件也不是锁。正常解锁后不删除锁文件，避免另一写者仍锁住旧 inode、后来写者锁住新 inode。等待锁只用单调时钟控制本次时限，不能把租约墙钟过期当作确认旧进程消失。

Python 的 `fcntl` 接口限于 Unix；Windows 的 `LockFileEx` 具有自己的句柄及锁区间语义，不能把一套 mock 结果写成三平台通过。附录只实现本地 POSIX 参考，并在当前 Linux 容器验证。[^W3][^W6]

#### 4.2.4 崩溃窗口及处理

| 故障点 | 可见内容 | 正确恢复行为 | 禁止行为 |
|---|---|---|---|
| 来源尚未提交/封存 | 暂存或不完整来源 | 标记 pending，等待所属模块恢复 | 文件存在即完成 |
| 来源提交，索引未追加 | 完整来源，无项目事件 | 扫描并按稳定键补录一次 | 仅重放现有 events 后宣布完成 |
| 索引一行写到一半 | 有效前缀+无 LF 尾部 | 隔离原字节，显式修复后再补录 | 把半条解释成成功或直接接着拼 JSON |
| 最后整行 JSON 完整但没有 LF | 按本协议仍是未完整帧 | 诊断并经恢复流程决定重建 | 自动假装已有提交分隔符 |
| 某个带 LF 的完整行非法 | 索引结构损坏 | 暂停投影前进，保留原文件并重建/裁决 | 当普通尾部丢弃或跳过继续 |
| 完整索引行已写，响应丢失 | 同源事件已经存在 | 同键返回原回执 | 换新 event_id 重写 |
| 日志已同步，缓存未更新 | 日志比缓存新 | 重放有效日志修复缓存 | 根据缓存“未见过”再追加 |
| state 临时文件写一半 | 旧完整 state+临时垃圾 | 原指针继续指向旧视图；新建完整版本 | 暴露半文件 |
| state 已完成，brief 未完成 | 未提交视图目录 | 不切 current 指针；保留待补偿候选 | 认定两文件同时完成 |
| manifest 已完成，指针未切 | 完整孤儿视图包 | 校验后按 CAS 重新发布或保留 | 自动抢占更晚指针 |
| current 已切，响应丢失 | 新完整视图已可读 | 查询指针/manifest，返回已有结果 | 重渲染不同内容冒充原发布 |
| 读取回执写入失败 | 已返回内容但无可靠 ack | 显示未知/未登记，允许同键补交 | 推断用户未读或已理解 |
| 备份回退丢失撤销/接受变化 | 旧索引与旧来源均可能自洽 | 恢复隔离，核对可信高水位和当前权威记录 | 仅凭文件哈希一致恢复新派遣 |

修复尾部只针对可重建项目索引，不对真实运行证据做截断。应先锁定、核对 `expected_index_sha256`、保存全文件副本和尾部摘要，再替换为有效前缀；发生完整行损坏不能走“自动去尾”快路径。

#### 4.2.5 来源补录算法

```text
reconcile(scope, producer_registry):
  capture source-cut / enumeration token for each registered producer
  enumerate committed records within declared scope and cut
  for each record:
    verify completion + identity + schema + resource bytes
    derive stable SourceKey and registered lifecycle facts
    append idempotently; record conflicts instead of replacing
  recheck producer cut / follow bounded deltas using producer contract
  report incomplete pages, pending records, inaccessible objects and index lag
  seal SourceScanReport
  publish new projection only with explicit coverage status
```

生产者有事务 outbox 时，可在生产者权威事务中同时登记业务事实和待索引通知；消费仍按稳定键幂等。**这是后续接线方案，不表示原项目已经有 outbox**。不具备事务源时，使用原始证据的提交清单与扫描作为补偿边界，明确覆盖截止点。

扫描只遍历注册的来源根和记录类型，不从用户日志、任意项目 JSON 或 Observer 文本提取 `PASS`。完成分页才能报告该范围完整；无 `next_page` 不等于上层数据源保证全面，需要来源接口的真实契约。

若最新源记录被删，索引中的旧引用仍要报告 missing，不能因为“当前扫描没看到它”就从历史中擦掉。来源库合法删除应提供明确保留/撤回事实和历史访问策略，而不是单凭目录缺失推断业务撤销。

#### 4.2.6 归约顺序与冲突

实体内部按生产者修订和前驱链归约；跨实体依赖通过固定引用连接。生产者版本缺口、两个同代 head、悬空前驱、跨 scope 替代、循环替代都进入明确未核实状态。

1. 先校验事件 framing、generation 和游标，再校验来源字节及上下文。
2. 将有效来源按实体事实流分组；迟到记录可以补全历史链，但不自动成为最新版本。
3. 校验每条来源链的前驱关系和版本；有冲突则保留历史已知值，当前关系标为 UNKNOWN/CONFLICTED。
4. 对当前有效 head 执行领域适配器归约；依赖缺失可展示 pending，不擅自推定前驱成立。
5. 形成历史事实轴和当前有效性轴；计数从当前有效的唯一实体集合派生，不执行 `completed += 1`。
6. 合并阻塞与预算观察，按固定规则排序，生成可复算输出。

对于重复“已完成”事件，重新计算任务集合的计数天然不重复推进；但这不能替代事件级和来源级去重。一个任务新合同版本、多个 attempt 或多个检查结果不应变成多个“已完成任务”。

#### 4.2.7 项目状态模型：不要只有一个 DONE

| 维度 | 建议内容 | 当前性解释 |
|---|---|---|
| 目标/决定 | 当前已确认版本、提议、冲突、来源 | 已确认不代表增加业务权限 |
| 规划 | REQUESTED、PLANNING、DRAFT_READY、NEEDS_PLAN_REVIEW、APPROVED | 沿用 09；APPROVED 不等于可派遣 |
| 合同 | 草稿、候选、完整发布版本、MD/JSON 引用 | 缺半份文件显示 publication_incomplete |
| 审核 | 登记结论、CURRENT/SUPERSEDED/REVOKED、验证观察 | 历史批准与当前适用分开 |
| 运行 | 原 attempt 状态、run、START_UNKNOWN、清理观察 | 进程事实只由 05/核心提供 |
| 检查 | candidate/check-set/environment/结果 | 针对 K1 的结果不能套到 K2 |
| 接受 | 未接受、正常接受、例外接受、撤销 | 例外接受单独计数和展示，不能显示普通 PASS |
| 集成 | 未知/未集成/已集成/已替代及真实引用 | 已集成历史不因后来撤销而被擦除 |
| 依赖/基线 | 07 的已接受输入、真实基线绑定、使用许可、等待 | 图上的依赖已满足不自动授予基线权限 |
| 预算 | 账本版本、已知小计、预留、未知覆盖、停止事实 | 只展示，不再次记账 |
| 健康度 | 完整、局部、过期、冲突、待恢复 | 不与任务业务状态复用一个枚举 |

展示推导例：

| 已有可靠事实 | 展示建议 | 不能显示 |
|---|---|---|
| attempt 正常退出，尚无 verdict | 执行结束，待复审 | 已验收 |
| 检查 PASS，尚无主模型接受 | 检查通过，待接受 | 已完成跨任务交付 |
| 对 K1 已接受，未集成 | 已验收，未集成 | 已在主基线中可用 |
| 已集成后接受被撤销 | 已集成历史保留，当前需复核 | 从未集成，或仍然可无条件复用 |
| 结果被 K2 替代 | 已替代；保留 K1 证据及后继 | 删除旧结果或把旧 PASS 改成 K2 PASS |
| 运行启动未知 | 恢复待决，可能有副作用 | 未启动，可以免费重跑 |
| 最新审核来源缺失 | 当前审核未核实，显示最后已知历史 | 自动回退旧 APPROVED |

基础投影可以不等待 09 完整实现，但必须把“规划生命周期未接入”显示为范围限制，而不是空列表等于没有待审规划。

#### 4.2.8 确定性投影与新鲜度

定义建议：

```text
ProjectState = Reduce(
  fixed_index_prefix,
  fixed_source_records,
  source_verification_snapshot,
  producer_coverage_vector,
  explicit_as_of_time,
  versioned_reducer_and_schema_registry,
  visibility_scope
)
```

纯 reducer 不再读取当前时间、随机数、网络、环境变量或可变“当前配置”。需要判断过期时，把观察时点和 03 的验证观察作为输入。相同事件游标下若来源核验结果、权限可见范围或期限判断发生变化，输出允许变化，但必须形成新的输入版本/观察记录；不能宣称只有游标就足以缓存整个状态。

建议 `ProjectState` 至少记录 `indexed_cursor`、`applied_cursor`、`source_vector`、`verification_ref`、`as_of`、归约/Schema 引用、来源集合引用、任务/决定/预算视图、问题清单与 `dispatch_eligibility=not_evaluated`。生成耗时、当前机器 PID、构建完成墙钟等运行元数据放独立构建记录，避免让同输入的 state 字节随机变化。

对外区分：

- **截至某时的可复算视图**：输入固定，可能已经过期。
- **当前观察视图**：刚完成来源/权威状态核对，但只承诺该观察切面。
- **即将执行的动作准入**：由 03/07 在动作边界重新检查，不由 10 提供。

普通进度更新可以推进显示游标，但不推进某个审核的相关依赖 generation。相反，时间到期可能没有任何新业务事件，也必须让“当前有效”观察过期；不能仅订阅事件而永久缓存批准。

#### 4.2.9 多文件一致发布与原子指针

单次 `os.replace` 不能把两个不同目标文件变成一个原子事务。建议发布步骤：

```text
固定投影输入 → state 最终字节 → brief 最终字节
  → 写入新 views/<view-id>/state.json 与 brief.md 并同步
  → manifest 引用两份完整字节及渲染/省略元数据
  → 写入并同步 manifest；校验包完整
  → 在写者锁内 CAS 核对旧 current 指针及未回退游标
  → 原子替换 current.json，按平台能力同步目录
  → 更新兼容展示 state.json/brief.md（可滞后，不是事务真相源）
```

读取路径必须先固定一个 `current.json` 版本，再读取它引用的 immutable manifest 和该包内文件。禁止打开顶层 state 后再打开另一次“最新”brief，并假设它们属于同一视图。

`view_id` 可以来自输入/渲染版本的带域摘要，不得被描述成文件自己的 SHA-256；每个 ResourceRef 仍单独核验对应完整文件字节。manifest 引用 state/brief，独立 current 指针引用 manifest，避免反向哈希循环。

Python 文档说明 `os.replace` 成功时的原子重命名语义以及跨文件系统限制；缓冲文件需先 flush 再 fsync。**原子可见、操作系统同步返回与断电后一定持久是不同保证**，目录同步、Windows 共享句柄、杀毒软件占用和底层文件系统仍需目标环境验收。[^W1]

较慢构建不能覆盖较新 current。至少 CAS 比较旧指针 hash/generation，并拒绝同代游标回退；若构建期间索引已前进，可拒绝发布并重建，或明确发布一个 `lagging` 历史视图，不能标为最新。附录选择前者。

#### 4.2.10 索引重建、generation 与历史游标

只删除 state/brief 时，用同一有效事件序列、固定核验输入和规则重建，应得到同样的确定性字节。这对应 `10-A02`/`10-A05` 的核心测试。

若整个索引丢失或必须重排：来源只能重建业务事实，不一定重建原登记顺序。无可靠旧游标分配清单时，创建新的 `index_generation`，保留旧代诊断/备份，不把新 seq=100 与旧 seq=100 当同一位置。

消费者带旧代游标查询新代时返回 `RESET_REQUIRED`，提供新基准视图及迁移/重建报告。读取回执继续引用旧 brief，不重写成“读过新版本”。预算根、任务身份与原始来源 ID 不随索引换代改变。

只做事件哈希链可以发现部分篡改，不能证明整个目录未被同权限进程一致重写，也不能检测没有可信外部高水位时的完整旧备份回滚。未来增加签名或外部高水位属于独立安全设计；没有实现时明确记录保证不足。

日志分段、压缩和快照是性能优化，不得删除仍被旧 brief、读取回执、审核或未完成任务引用的证据。段 manifest 应列起止游标、前段引用、完整字节 hash 和覆盖来源；回收按所属模块保留策略执行，10 不自行清理真实 `.agent/runs/`。

#### 4.2.11 相关失效、诊断与业务门禁

10 可展示 03 的失效观察，也可发现需重新核验的来源漂移；**不能直接把显示中的 `invalid=true` 当成真实撤销事务已经提交**。如果业务动作必须立即暂停，03/07 要共享权威守卫或读取所属源的当前状态，不能等待 10 的通知才生效。[^P03]

| 变化 | 简报/状态 | 审核与派遣 |
|---|---|---|
| 新进度、普通心跳、读取回执 | 可更新进度或仅更新遥测 | 不使无关审核失效 |
| 同一相关合同/规则/配置/插件/基线变化 | 展示具体变化及依赖路径 | 03 按实际相关绑定拒绝旧审核 |
| 非所选 profile、另一 request 的无关进度 | 不扩散到当前事实范围 | 不连带撤销 |
| A→B→A 受控绑定发布 | 保留代际变化来源 | 采用 03 的绑定代际规则时不得自动复活旧审核 |
| 损坏字节恢复成精确原字节 | 生成新的完整性观察 | 不清除真实撤销、过期或变更历史 |
| renderer 变更 | 新 brief 版本，旧读取仍指旧字节 | 不因排版变化取消合同审核 |

不要把整个 state/brief 的 hash 作为所有合同共享的授权依赖，否则任何进度变化都会让所有审核失效。业务动作只绑定其真正依赖的需求、规则、合同、配置、候选和授权来源。

### 4.3 简报、反馈与用量

#### 4.3.1 简报信息结构

原文要求的目标与非目标、规则索引、已确认决定、任务依赖、基线/候选、运行项、阻塞、预算和下一动作全部保留。每条信息应区分**已登记事实、提议/假设、未核实、过期、冲突**，并标注最小来源。[^P10]

| 区块 | 最低信息 | 不得省略的限定 |
|---|---|---|
| 观察头 | 项目/request、generation、游标、as_of、来源覆盖、渲染版本 | 非当前或扫描不完整的警告 |
| 目标/非目标 | 具体已确认版本及来源 | 未确认目标不能混入确认段 |
| 规则索引 | 当前适用规则的固定引用和作用域 | 高风险限制、读取规则的下一步 |
| 决定 | 当前确认、被替代/撤销与待决冲突 | 决定不是新增权限 |
| 任务与依赖 | 状态维度、输入/基线等待、候选版本 | 可细化不等于可执行 |
| 正在运行/未知启动 | attempt/run、观察时间、采集/清理缺口 | START_UNKNOWN、残留未知不可隐藏 |
| 阻塞/停止 | 原因、影响范围、责任模块及安全下一步 | 不把请求停止当作所有进程已停止 |
| 预算 | 07 快照、币种小计、预留、未知覆盖、停止边界 | 不输出无法支持的总 token/总费用 |
| 下一动作 | 检查来源、请求审阅、确认基线或恢复事实等建议 | 不是自动命令执行，也不是派遣许可 |
| 省略元数据 | 条目数量、类别、未展示对象索引 | 内容不足时明确停止形成“完整简报” |

“事实”可表示“某受信来源记录了某结论”，不自动意味着结论所指业务语义已经由本模块证明。例如“检查记录显示对 K1 通过”比“系统已修复”更准确；后者需要相应验收来源。

#### 4.3.2 BriefItem 与限长算法

建议 `BriefItem` 字段：稳定 item ID、section、类别、严重度、实体范围、来源引用、短文本、是否必须保留、相关动作/阻塞代码。关键性来自受信规则，不从原始日志中的 `priority` 字段直接相信。

首期长度上限使用 **UTF-8 字节数**，不是未经验证的“token 数”。若另加模型 tokenizer 限额，需要锁定 tokenizer 与目标模型版本，并说明它只是输入 token 估计，不代表主会话整体费用已可观测。

```text
构造固定排序的 BriefItem 集合
  → 先放安全头、全部必须项、引用和省略说明的预留字节
  → 必须项放不下：返回 E_BRIEF_BUDGET_TOO_SMALL，不生成看似完整的 brief
  → 按稳定优先级加入可选条目，条目与引用一起保留或一起省略
  → 在完整 UTF-8 输出上重算字节数，计入头、引用、换行、脚注和省略说明
  → 封存 included_item_ids / omitted_item_ids / source_refs / rendered_bytes
```

排序建议为关键性、区块优先级、严重度、稳定实体 ID、来源版本；锁定字符串比较规则，不依赖系统 locale、目录枚举或当前时间。不能通过把时间戳改成“刚刚”使同输入输出不确定。

以下内容默认是必须项：来源覆盖/损坏警告、停止原因、未知启动/残留、正在影响下一动作的安全规则和决定冲突、预算未知/停止状态，以及“简报不代表授权”的说明。限制太小时可以另返回安全失败说明及 `required_min_bytes`，但不得把丢失关键限制后的摘要标为正常。

简报截断与数据源缺失是两类问题：`truncated=true` 表示已知内容因长度未展示；`source_coverage=partial` 表示可能还有尚不知道的事实。不能用同一个“已省略”掩盖扫描缺口。

#### 4.3.3 来源引用与语义支持

每个已展示的业务事实至少关联实际资源引用、该来源中的字段/记录定位，以及适用的 request/task/candidate。大段日志只提供最小可读定位；其完整字节由原资源引用锁定。

对于字节区间，使用明确的半开区间 `[start_byte,end_byte)` 和编码/脱敏版本。不能把字符偏移、原始流偏移、脱敏后偏移混在一起；本模块不重新定义 01/04 的原始证据坐标。

确定性渲染器从结构化字段输出受控措辞。必须自由撰写的目标/决定文本保留来源身份和“原文/提议”边界。参考实现只能证明确定性抽取与展示，不证明开放式语义支持，也不检测所有事实错误。

#### 4.3.4 读取、宿主和输出安全

仓库文本、日志、决定理由和 Observer 建议均可能包含要求模型“忽略规则、直接执行”的内容。它们作为数据呈现，不会因为进入 brief 而升级为 supervisor 指令。OWASP 的提示注入资料支持将可信指令与外部内容分隔、限制工具副作用并实施独立校验；单靠转义和标签不是完整防护。[^W8]

建议渲染规则：固定标题、转义不受信 Markdown/HTML、禁止直接插入任意图片或远程链接、可视化控制字符和双向控制符、不自动展开 shell 块、不根据来源文本运行命令。来源的完整字节保持不变，展示层安全转换使用独立版本。

读取必须先检查请求主体对 project/request 和相关来源的可见权限。即使返回的只是标题、候选名、费用或“此记录存在”，也可能泄露未授权范围。宿主推送须绑定已批准的接收目标、可见范围和外发策略，不把“仅发送简报”当成无需授权的外发。

原文要求摘要有来源；这不意味着把全部原始源码、日志和凭据复制进 brief。脱敏和最小展示先于外发，禁止在异常、Schema 诊断、通知正文和读取回执里保存明文凭据。

#### 4.3.5 简报发布与读取协议

建议分成两个显式动作：

```text
GET/CLI project brief
  → 固定一个 current manifest
  → 校验 manifest、state 和 brief 字节
  → 返回 brief 字节 + manifest_ref + brief_ref + cursor + freshness + truncation

project acknowledge-read
  → 提交明确 session/checkpoint、实际收到的 brief_ref、cursor、manifest_ref
  → 校验对应 immutable 视图确实存在且引用一致
  → 幂等登记 BriefReadReceipt
```

建议读取回执至少记录：会话来源、检查点、brief/manifest 固定引用、generation/游标、观察类型、登记时间、已返回范围及省略情况。`understanding_verified` 固定为 false 或明确不提供；不设置模型理解分数。

| 证据 | 可写出的状态 | 不可写出的状态 |
|---|---|---|
| brief 文件封存 | GENERATED | DELIVERED/READ |
| pull 命令返回了字节 | RETURNED_TO_CALLER | 主模型一定已看到或理解 |
| host API 接收请求 | HOST_ACCEPTED | 实际终端已展示 |
| 宿主提供真实展示回执 | DELIVERED_REPORTED | 已读或已遵守 |
| 会话明确确认某份 brief | READ_ACKNOWLEDGED | 已理解全部规则 |
| API 超时、回执丢失 | DELIVERY_UNKNOWN/ACK_UNKNOWN | 自动当失败重发新内容，或自动当已读 |

读取回执的幂等键绑定会话、检查点和精确 brief/manifest；同键重送返回首次登记时间，不制造多个“已读次数”。回执不能被其他 request 或新 brief 复用。旧 brief 已被新版本替代时，历史读取仍成立，但下一动作是否需要刷新取决于相关内容和当前守卫，不把过去回执重写成当前已读。

#### 4.3.6 刷新检查点和避免自激循环

原刷新点保留：会话恢复、规划审核、prepare/run、check/verdict/integration，以及失败或规则变化。纯心跳只有实际进度变化或阻塞变化才形成增量提示。[^P10]

推荐将输入分为：

| 水位 | 包含 | 是否使业务简报重渲染 |
|---|---|---|
| `business_content_watermark` | 目标、决定、任务、相关规则、预算/阻塞变化 | 是 |
| `verification_watermark` | 来源完整性/时效观察发生有意义变化 | 是 |
| `delivery_watermark` | 发送尝试、宿主回执 | 默认否 |
| `read_watermark` | 读取/确认记录 | 默认否 |

禁止 `brief_generated → project event → 新 brief → brief_generated` 循环。读取记录更新不能改变 brief 自身所依赖的业务游标；需要统一审计时用独立遥测游标。Observer 建议只有经过主模型确认并形成新的正式决定来源后，才进入“已确认”区块；确认前保持单独建议视图。

#### 4.3.7 pull、可选 push 与未知投递

无真实宿主接口时，明确输出 `delivery_mode=pull`，提供查询说明，不尝试通过写文件唤醒会话。自动化触发或推送应由实际宿主/外部服务实现，不能由本文假定存在。

可选 host adapter 的计划字段建议包括：宿主类型、接收目标安全绑定、request 可见范围、brief 固定引用、幂等 delivery ID、有效期和最大外发长度。发送结果保留宿主实际返回的消息 ID/接收状态；缺展示/已读回执时保持未知。

对超时或响应丢失，优先按同 delivery ID 查询真实提交结果。没有幂等/查询能力时记录重复风险；不换 ID 自动反复发送。不允许 host adapter 将收到的源文本解释为审核/派遣命令。

#### 4.3.8 用量与预算：只投影，不记第二笔账

以 `request_id` 展示规划、执行、独立复审工具和可选摘要的可观测消耗。来源仍是 07 的预算账本及其固定快照；10 不从项目事件自行累计 token/金额，不把 `BudgetSnapshot` 写回为新的消费分录。[^P07]

| 情况 | 展示规则 |
|---|---|
| 同一 ledger revision 重复索引 | 仍展示一次，不增加费用 |
| 累计快照从 USD 5.20 更新为 USD 6.10 | 当前已知小计 6.10，不是 11.30 |
| USD 6.10 和 EUR 2.00 | 分币种显示；无已审汇率政策不输出统一总额 |
| 已知一部分费用、另有未知调用 | `known_subtotal + unknown_call_count/IDs + coverage`；不能显示“总费用=已知小计” |
| 主会话用量不可观测 | `unknown`，说明范围；不宣称测得主模型节省比例 |
| 最新账本来源缺失或修订链冲突 | 当前预算未知，保留历史观察；不回退旧较低小计冒充余额 |
| 迟到费用使实际超预算 | 展示 07 的真实更新与停止状态；不截断费用以保持余额非负 |
| Observer 未启用 | 不虚构一次零费用调用；确定性 brief 没有模型调用 |

金额采用十进制字符串或所属账本规定的精确表示，不使用二进制 float 做财务汇总。即使本模块只是显示，也不要先转 float 再格式化造成金额变化。调用次数、并发和时限的机械边界由 07 执行，本模块只说明其来源和观察时点。

“减少重复阅读日志”是设计目标，不是本次量化的 token 节省结论。可以实测渲染字节数、来源定位数量和操作耗时，但不能用字节减少比例冒充所有模型的 token/费用减少比例。

#### 4.3.9 只读接口、变更接口与错误

以下为拟议接口，**不是已在用户项目安装的命令**。运行示例见附录参考包，不能把它们与原调度器命令混为一谈。

| 接口 | 行为 | 副作用边界 |
|---|---|---|
| `project status --request-id … --format json` | 读固定状态并报告游标/时效 | 默认不扫描修复、不派遣、不记费用 |
| `project brief --request-id … --max-bytes …` | 返回固定简报/元数据 | 是否生成新视图须显式配置；不自动确认已读 |
| `project changes --after-generation … --after-seq …` | 同代增量 | 跨代 RESET_REQUIRED，不从错误位置继续 |
| `project verify --scope …` | 核验固定来源并给诊断 | 可保存新核验报告，不修改业务来源 |
| `project reconcile --dry-run` | 列待补录和冲突 | 不追加索引 |
| `project reconcile --apply --expected-generation …` | 幂等追加经核验来源 | 需索引维护权限，不触发任务 |
| `project repair-index --plan-ref … --expected-index-sha256 …` | 受控尾部/重建修复 | 需维护授权、锁、备份、CAS 和结果报告 |
| `project acknowledge-read --manifest-ref … --brief-ref …` | 登记具体版本读取 | 仅写读取记录；不改变授权 |
| `project notify --delivery-plan-ref …` | 可选宿主发送 | 必须有真实接口和外发授权 |

建议错误家族：

| code | 条件 | 安全恢复方向 |
|---|---|---|
| `E_SOURCE_MISSING/INCOMPLETE/HASH/CONFLICT` | 来源缺失、未封存、漂移或同身份冲突 | 核验所属模块，不以旧成功回退 |
| `E_SOURCE_SCOPE/PRODUCER/BINDING` | 来源与范围/提取器不一致 | 修正登记或映射，不能放宽路径读取 |
| `E_SCAN_INCOMPLETE` | 扫描尚未覆盖声明切面 | 保留局部状态，补齐受控扫描 |
| `E_INDEX_TAIL/LINE/CURSOR` | 尾部、完整行或序号异常 | 保存原字节，执行明确修复方案 |
| `E_REVISION_CHAIN` | 缺前驱、fork、跨范围链 | 待补录或主模型裁决，不按最后写者获胜 |
| `E_VIEW_CAS/HEAD_CHANGED/ROLLBACK` | current 并发变化、构建落后、版本回退 | 重新固定输入或读取已发布视图 |
| `E_BRIEF_BUDGET_TOO_SMALL` | 关键项加来源无法装入上限 | 提高显式上限/分批读取，不能删安全限定 |
| `E_READ_MISMATCH` | 回执不是该视图的 hash/游标 | 返回真实已读版本；不伪造当前已读 |
| `E_DELIVERY_UNKNOWN` | 无法判明宿主提交结果 | 同 ID 查询，避免盲目重发 |
| `E_PLATFORM_UNSUPPORTED/LOCK_BUSY` | 锁后端缺失/争用 | 显示平台缺口或有限等待 |

错误使用 01 的稳定结构；详情只包含安全的字段/范围/资源位置，不输出敏感原始内容。新增数值退出码需在正式接线时与 01 和旧入口对齐，不能把旧 `wait=3` 重新解释成本模块业务状态。`retryable=true` 依旧不授权重试模型或恢复派遣。[^P01]

#### 4.3.10 可观测性、性能与容量

建议度量：有效索引头与投影游标差、各生产者扫描覆盖、待补录数量、来源冲突/缺失、旧代游标请求、视图发布 CAS 失败、必需项超长、投递未知、最后成功核验时间及恢复耗时。度量标签避免直接使用正文、凭据或高基数源路径；对象级细节进入受控诊断。

下表为待压测初值，不是项目现有配置或本次性能结论：

| 参数 | 建议初值 | 到达上限 |
|---|---:|---|
| 单项目事件行 | 64 KiB | 拒绝大 payload，改为资源引用 |
| 严格 JSON 嵌套 | 48–64 层，按家族冻结 | 明确解析限额错误 |
| 默认 brief | 16 KiB UTF-8 | 条目级省略；关键项不足时报错 |
| 单次读取最高 brief | 256 KiB | 超限拒绝，不静默改成无限制 |
| 来源扫描 | 分页、有限批次、可恢复高水位 | 报告 partial 而非阻塞无限久 |
| 单次锁等待 | 数秒级、由操作类型冻结 | 显示忙，不启动第二独立写者 |
| 来源哈希缓存 | 仅对可证明不可变版本复用 | mtime/大小相同不单独构成完整性证明 |

附录原型为小规模全量重放，日志上限 32 MiB、单 JSON/资源读取上限 1 MiB，**与以上生产建议是不同 profile**，没有宣称百万事件或生产 p95 指标。大规模方案可加由日志重建的索引缓存、分段和持久快照，但应先证明缓存缺失/滞后不会改变事实或漏掉撤销。

## 8. 兼容与恢复

### 8.1 v1、旧状态与映射

原文保留：旧 attempt 缺 v2 字段时保留 unknown 和来源年代；不补造当年的审核、模型或预算证据。历史任务不能凭文字摘要自动归入 request；显式映射要记录确认来源。回退新入口时保留项目记录，旧 status/metrics 按原语义运行；决定纠正用新版本，不覆盖旧版本。[^P10]

兼容适配器应输出 `legacy_observation` 的保证级别。缺 source revision 的历史观察无法证明完整替代链时，显示“最后可核验观察”，不能声称与 v2 的来源版本/撤销覆盖相同。旧 summary 只用于定位，不升级为新式批准。

### 8.2 操作人员十步恢复流程

这里给出应落实到维护命令的步骤。**生产命令尚未实现时，不用手工编辑状态 JSON 或添加 approved 字段代替。**

| 步骤 | 操作 | 成功判据 | 失败升级 |
|---|---|---|---|
| 1 | 在 07 受控入口阻止受影响范围的新派遣；记录恢复范围和维护授权 | 新动作受权威守卫阻止；必要采集/清理仍可继续 | 无法确认停止生效则升级主控负责人，不触碰未知进程 |
| 2 | 保存索引、current、相关来源清单、核验/读取记录的只读副本及 hash | 副本可读、范围和保留位置登记 | 存储不可用时停止修复，不覆盖唯一副本 |
| 3 | 获取稳定写者锁，确认 repository/project/generation 和实际控制器 | 当前锁独占、身份与预期一致 | 不删除 lockfile 或仅按 PID 认定可接管 |
| 4 | 核验完整日志前缀、游标、来源键和尾部 | 明确区分未完整尾部、完整行损坏和同源冲突 | 中间损坏/身份冲突进入重建或人工裁决，不自动去尾 |
| 5 | 执行已审修复计划，使用 expected hash/CAS，保留原字节 | 只改变可重建索引，形成 RecoveryReport | CAS 变化则重新检查，禁止强制忽略 |
| 6 | 按真实生产者提交清单扫描补录 | 所有已声明 cut 均有覆盖报告；缺项明确列出 | 来源不完整/权限不足保持 partial |
| 7 | 核对 03 当前撤销/绑定、07 接受/账本、09 发布和 05 未知运行 | 不依赖旧缓存判断当前权限；START_UNKNOWN 有对应待决项 | 未能核对则不恢复新派遣 |
| 8 | 重新固定核验快照，重建 state/brief/manifest 并 CAS 发布 | 完整包自洽、没有游标/观察回退、哈希一致 | 保留旧完整视图，新包隔离 |

正常恢复应保留哪些事实：真实已发生的运行、费用、候选、接受、集成和后继关系，以及当前不确定项。不能为了让仪表盘变绿而把 `unknown` 改成 false、删掉失败 attempt、退回旧预算或复活旧批准。

### 8.3 恢复验收与回退

恢复后至少核对：同来源只登记一次、任务计数不增加、当前接受/集成与权威来源一致、预算快照版本不退回、停止/未知启动可见、未核实来源未被标为有效、新 brief 的固定引用可追溯、旧读取回执没有被改成新版本。

回退新入口只停用新能力，不删除已经产生的审计记录；当前真实未决运行继续由 05/07 管理。不能因为回退到 v1 UI 就让 v2 草稿绕过审核，或按旧界面看不到某请求就把其费用清零。

locking, real producer adapters, retention/GC, and power-loss guarantees are absent.

from copy import deepcopy

from hashlib import sha256

MAX_LOG = 32 * MAX_JSON
MAX_INT = 9007199254740991
SCHEMA = json.loads(Path(__file__).with_name("project-reference.schema.json").read_text(encoding="utf-8"))

class Fault(Exception):
    def __init__(self, code: str, location: str = ""):
        self.code, self.location = code, location
        super().__init__(code)  # Never interpolate raw source content or credentials.


def fail(code: str, location: str = "") -> None:
    raise Fault(code, location)


def strict_load(raw: bytes, limit: int = MAX_JSON):
    if type(raw) is not bytes or len(raw) > limit:
        fail("E_JSON_LIMIT")
    if raw.startswith(b"\xef\xbb\xbf"):
        fail("E_JSON_BOM")
    def pairs(items):
        out = {}
        for k, v in items:
            if k in out:
                fail("E_JSON_DUPLICATE_KEY")
            out[k] = v
        return out
    def forbidden(_):
        fail("E_JSON_NUMBER")
    try:
        value = json.loads(raw.decode("utf-8", "strict"), object_pairs_hook=pairs,
                           parse_float=forbidden, parse_constant=forbidden)
    except (UnicodeError, ValueError, RecursionError):
        fail("E_JSON_SYNTAX")
    def walk(v, depth=0):
        if depth > 48:
            fail("E_JSON_DEPTH")
        if isinstance(v, str):
            if any(0xD800 <= ord(c) <= 0xDFFF for c in v):
                fail("E_JSON_UNICODE")
        elif type(v) is int and abs(v) > MAX_INT:
            fail("E_JSON_NUMBER")
        elif isinstance(v, list):
            for x in v:
                walk(x, depth + 1)
        elif isinstance(v, dict):
            for k, x in v.items():
                walk(k, depth + 1)
                walk(x, depth + 1)
    walk(value)
    return value


def canonical(value) -> bytes:
    try:
        raw = (json.dumps(value, ensure_ascii=False, sort_keys=True,
                          separators=(",", ":"), allow_nan=False) + "\n").encode("utf-8")
    except (ValueError, TypeError, UnicodeError):
        fail("E_JSON_OUTPUT")
    strict_load(raw, limit=MAX_LOG)  # Reference profile deliberately excludes all float fields.
    return raw


def digest(raw: bytes) -> str:
    return sha256(raw).hexdigest()


def validate(name: str, value) -> None:
    local = {"$schema": SCHEMA["$schema"], "$defs": SCHEMA["$defs"], "$ref": "#/$defs/" + name}
    error = next(Draft202012Validator(local, format_checker=FormatChecker()).iter_errors(value), None)
    if error:
        fail("E_SCHEMA", "/".join(str(x) for x in error.absolute_path))


def relative_path(value: str) -> tuple[str, ...]:
    if not isinstance(value, str) or not value or len(value) > 1024:
        fail("E_PATH")
    if value.startswith("/") or any(c in value for c in ("\\", ":", "\x00")):
        fail("E_PATH")
    parts = value.split("/")
    if any(p in ("", ".", "..") or p.endswith((" ", ".")) for p in parts):
        fail("E_PATH")
    return tuple(parts)


def read_resource(root: Path, resource: dict) -> bytes:
    """POSIX descriptor traversal. Root itself and its parents are trusted fixture paths."""
    validate("ResourceRef", resource)
    parts = relative_path(resource["path"])
    if os.name != "posix" or not hasattr(os, "O_NOFOLLOW"):
        fail("E_PLATFORM_UNSUPPORTED")
    fd = None
    try:
        fd = os.open(root, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)
        for part in parts[:-1]:
            nxt = os.open(part, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW, dir_fd=fd)
            os.close(fd)
            fd = nxt
        child = os.open(parts[-1], os.O_RDONLY | os.O_NOFOLLOW | os.O_NONBLOCK, dir_fd=fd)
        os.close(fd)
        fd = child
        before = os.fstat(fd)
        if not stat.S_ISREG(before.st_mode) or before.st_nlink != 1:
            fail("E_SOURCE_FILE_TYPE")
        chunks, total = [], 0
        while True:
            chunk = os.read(fd, min(65536, MAX_JSON + 1 - total))
            if not chunk:
                break
            chunks.append(chunk)
            total += len(chunk)
            if total > MAX_JSON:
                fail("E_SOURCE_LIMIT")
        raw = b"".join(chunks)
        after = os.fstat(fd)
        if (before.st_size, before.st_mtime_ns, before.st_ctime_ns) != (after.st_size, after.st_mtime_ns, after.st_ctime_ns):
            fail("E_SOURCE_CHANGED")
        if digest(raw) != resource["sha256"]:
            fail("E_SOURCE_HASH")
        return raw
    except FileNotFoundError:
        fail("E_SOURCE_MISSING")
    except OSError:
        fail("E_SOURCE_READ")
    finally:
        if fd is not None:
            os.close(fd)


def source_key(record: dict) -> tuple[str, str, str, str]:
    return tuple(record[k] for k in ("repository_namespace", "project_id", "producer", "source_record_id"))


def entity_key(record: dict) -> tuple[str, str, str]:

def event_identity(record: dict) -> str:

def sync_dir(path: Path) -> None:
    if os.name != "posix":
        fail("E_PLATFORM_UNSUPPORTED")
    fd = os.open(path, os.O_RDONLY | os.O_DIRECTORY)
    try:
        os.fsync(fd)
    finally:
        os.close(fd)


def atomic_file(path: Path, raw: bytes) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name("." + path.name + "." + uuid.uuid4().hex + ".tmp")
    with tmp.open("xb") as fh:
        fh.write(raw)
        fh.flush()
        os.fsync(fh.fileno())
    os.replace(tmp, path)
    sync_dir(path.parent)


def immutable_file(path: Path, raw: bytes) -> None:
    """Caller owns fixture directories and serializes concurrent publications."""
    if path.exists():
        if path.read_bytes() != raw:
            fail("E_IMMUTABLE_CONFLICT")
        return
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("xb") as fh:
        fh.write(raw)
        fh.flush()
        os.fsync(fh.fileno())
    sync_dir(path.parent)


def make_ref(kind: str, identity: str, path: str, raw: bytes) -> dict:

def read_log(raw: bytes, generation: str, repository_namespace: str, project_id: str):
    """Return validated full prefix plus raw incomplete tail; reject corrupt full lines."""
    if len(raw) > MAX_LOG:
        fail("E_INDEX_LIMIT")
    boundary = raw.rfind(b"\n") + 1
    prefix, tail = raw[:boundary], raw[boundary:]
    events, keys = [], set()
    for seq, line in enumerate(prefix.splitlines(keepends=True), 1):
        if not line.endswith(b"\n") or line in (b"\n", b"\r\n"):
            fail("E_INDEX_LINE")
        event = strict_load(line)
        validate("ProjectEvent", event)
        if (event["repository_namespace"], event["project_id"]) != (repository_namespace, project_id):
            fail("E_INDEX_SCOPE")
        if event["cursor"] != {"generation": generation, "seq": seq}:
            fail("E_INDEX_CURSOR")
        if event["event_id"] != event_identity(event):
            fail("E_EVENT_ID")
        key = source_key(event)
        if key in keys:
            fail("E_INDEX_DUPLICATE")
        keys.add(key)
        events.append(event)
    return events, prefix, tail


class EventIndex:
    """Single-writer, JSONL index; original fixture sources remain the fact authority."""
    def __init__(self, root: Path, generation="index-fixture-1", repository_namespace="repo-fixture", project_id="project-fixture"):
        self.root, self.generation = Path(root), generation
        self.repo, self.project = repository_namespace, project_id
        self.root.mkdir(parents=True, exist_ok=True)
        self.path = self.root / "events.jsonl"

    @contextmanager
    def writer(self, timeout=2.0):
        if os.name != "posix":
            fail("E_PLATFORM_UNSUPPORTED")
        import fcntl
        # Persistent lock inode: NEVER unlink this file after unlocking.
        with (self.root / "writer.lock").open("a+b") as fh:
            until = time.monotonic() + timeout
            while True:
                try:
                    fcntl.flock(fh, fcntl.LOCK_EX | fcntl.LOCK_NB)
                    break
                except OSError as exc:
                    if exc.errno not in (errno.EACCES, errno.EAGAIN):
                        raise
                    if time.monotonic() >= until:
                        fail("E_LOCK_BUSY")
                    time.sleep(0.005)
            try:
                yield
            finally:
                fcntl.flock(fh, fcntl.LOCK_UN)

    def read(self):
        raw = self.path.read_bytes() if self.path.exists() else b""
        return read_log(raw, self.generation, self.repo, self.project)

    def append(self, resource: dict, recorded_at="2026-09-25T00:00:00Z", crash_at=None):
        # The verified bytes, not a later re-open, supply the event metadata.
        src = strict_load(read_resource(self.root, resource))
        validate("SourceRecord", src)
        if resource["kind"] != "fixture-source" or resource["id"] != src["source_record_id"]:
            fail("E_SOURCE_BINDING")
        if (src["repository_namespace"], src["project_id"]) != (self.repo, self.project):
            fail("E_SOURCE_SCOPE")
        if src["producer"] != PRODUCERS[src["stream"]]:
            fail("E_SOURCE_PRODUCER")
        with self.writer():
            events, _, tail = self.read()
            if tail:
                fail("E_INDEX_TAIL")
            for old in events:
                if source_key(old) == source_key(src):
                    if old["source_ref"] == resource and all(old[k] == src[k] for k in COPY_FIELDS):
                        return old, True
                    # Both old and incoming scopes are tainted by identity reuse.
                    for scope in sorted({"/".join(entity_key(src)), "/".join(entity_key(old))}):
                        diag = {"code": "E_SOURCE_CONFLICT", "scope": scope, "source_ref": resource}
                        raw = canonical(diag)
                        immutable_file(self.root / "diagnostics" / (digest(raw) + ".json"), raw)
                    fail("E_SOURCE_CONFLICT")
            event = {"schema_version": 1, "record_type": "project-event", **{k: src[k] for k in COPY_FIELDS},
                     "cursor": {"generation": self.generation, "seq": len(events) + 1},
                     "event_id": event_identity(src), "recorded_at": recorded_at, "source_ref": resource}
            validate("ProjectEvent", event)
            raw = canonical(event)
            if crash_at == "before_append":
                fail("E_INJECTED_CRASH")
            with self.path.open("ab") as fh:
                fh.write(raw[:len(raw)//2] if crash_at == "partial_append" else raw)
                fh.flush()
                os.fsync(fh.fileno())
            sync_dir(self.root)
            if crash_at in ("partial_append", "after_append"):
                fail("E_INJECTED_CRASH")
            return event, False

    def repair_tail(self, expected_file_sha256: str, maintenance: bool):
        if not maintenance:
            fail("E_MAINTENANCE_REQUIRED")
        with self.writer():
            raw = self.path.read_bytes()
            if digest(raw) != expected_file_sha256:
                fail("E_REPAIR_CAS")
            events, prefix, tail = self.read()  # Full malformed lines are never auto-skipped.
            if not tail:

            backup = self.root / "quarantine" / (digest(raw) + ".bin")
            immutable_file(backup, raw)
            report = {"before_sha256": digest(raw), "prefix_sha256": digest(prefix),
                      "tail_sha256": digest(tail), "valid_events": len(events)}
            immutable_file(self.root / "recovery" / (digest(raw) + ".json"), canonical(report))
            atomic_file(self.path, prefix)
            return {"repaired": True, **report}

    def reconcile(self, catalog: list[dict]):
        """Catalog is provided by the trusted fixture builder; not a real source scanner."""
        added, replayed, errors = 0, 0, []
        for resource in sorted(catalog, key=lambda r: (r["id"], r["sha256"], r["path"])):
            try:
                _, replay = self.append(resource)
                replayed += int(replay)
                added += int(not replay)
            except Fault as exc:
                errors.append({"source_id": resource["id"], "code": exc.code})
        return {"added": added, "replayed": replayed, "errors": errors}

    def diagnostics(self):

        for path in sorted((self.root / "diagnostics").glob("*.json")):
            value = strict_load(path.read_bytes())
            validate("Issue", value)
            result.append(value)
        return result

    datetime.fromisoformat(as_of.replace("Z", "+00:00"))
    events, _, tail = index.read()
    issues = index.diagnostics()

            scope = "/".join(entity_key(e))
            issues.append({"code": "E_CATALOG_CONFLICT", "scope": scope, "source_ref": expected[identity]})
            blocked.add(scope)
    for e in events:
        scope = "/".join(entity_key(e))
        try:
            src = strict_load(read_resource(index.root, e["source_ref"]))
            validate("SourceRecord", src)
            if e["source_ref"]["kind"] != "fixture-source" or e["source_ref"]["id"] != src["source_record_id"]:
                fail("E_SOURCE_BINDING")
            if not all(src[k] == e[k] for k in COPY_FIELDS):
                fail("E_SOURCE_BINDING")
            if src["producer"] != PRODUCERS[src["stream"]]:
                fail("E_SOURCE_PRODUCER")
            groups[entity_key(src)].append((src, e["source_ref"]))
        except Fault as exc:
            blocked.add(scope)
            issues.append({"code": exc.code, "scope": scope, "source_ref": e["source_ref"]})
    entities = []
    for key in sorted(groups):
        scope = "/".join(key)
        chain = sorted(groups[key], key=lambda pair: (pair[0]["revision"], pair[0]["source_record_id"]))
        previous = None
        for rev, (src, resource) in enumerate(chain, 1):
            if src["revision"] != rev or src["previous_record_id"] != previous:
                blocked.add(scope)
                issues.append({"code": "E_REVISION_CHAIN", "scope": scope, "source_ref": resource})
                break
            previous = src["source_record_id"]
        if scope in blocked:
            continue  # Never silently fall back to an older approved/accepted snapshot.
        src, resource = chain[-1]
        value = deepcopy(src["value"])
        if src["stream"] == "approval":
            expiry = value["valid_until"]
            if expiry and datetime.fromisoformat(expiry.replace("Z", "+00:00")) <= datetime.fromisoformat(as_of.replace("Z", "+00:00")):
                issues.append({"code": "E_APPROVAL_STALE", "scope": scope, "source_ref": resource})
        if src["stream"] == "budget":
            currencies = [x["currency"] for x in value["currencies"]]
            if len(currencies) != len(set(currencies)) or value["ledger_revision"] != src["revision"]:
                issues.append({"code": "E_BUDGET_SNAPSHOT", "scope": scope, "source_ref": resource})
                continue
        entities.append({"request_id": src["request_id"], "stream": src["stream"], "subject_id": src["subject_id"],
                         "revision": src["revision"], "source_ref": resource, "value": value})
    tasks = []
    for ent in entities:
        if ent["stream"] != "task":
            continue
        v = ent["value"]
        valid = True
        if v["verdict"] == "PASS" and (v["candidate_id"] is None or v["candidate_id"] != v["checks_candidate_id"]):
            valid = False
        if v["acceptance"] == "ACCEPTED" and (v["verdict"] not in ("PASS", "EXCEPTION_ACCEPTED") or v["acceptance_record_id"] is None):
            valid = False
        if v["integration"] != "NONE" and v["acceptance_record_id"] is None:
            valid = False
        accepted = valid and v["acceptance"] == "ACCEPTED"
        if not valid:
            display = "unverified"
            issues.append({"code": "E_TASK_BINDING", "scope": "/".join((ent["request_id"], "task", ent["subject_id"])), "source_ref": ent["source_ref"]})
        elif v["integration"] == "SUPERSEDED":
            display = "superseded"
        elif v["integration"] == "INTEGRATED":
            display = "integrated" if accepted else "integrated-requires-review"
        elif accepted:
            display = "accepted" if v["verdict"] == "PASS" else "exception-accepted"
        elif v["attempt_status"] == "START_UNKNOWN":
            display = "recovery-required"
        elif v["attempt_status"] == "TERMINAL":
            display = "needs-acceptance" if v["verdict"] == "PASS" else "needs-review"
        else:
            display = v["attempt_status"].lower()
        tasks.append({"request_id": ent["request_id"], "task_id": ent["subject_id"], "display_state": display,
                      "effective_acceptance": accepted and v["integration"] != "SUPERSEDED",
                      "historically_integrated": valid and v["integration"] != "NONE", "source_ref": ent["source_ref"]})
    present_tasks = {(t["request_id"], t["task_id"]): t for t in tasks}
    task_entities = {(e["request_id"], e["subject_id"]): e for e in entities if e["stream"] == "task"}
    remaining = set(task_entities)
    while remaining:
        ready = {key for key in remaining if all(
            (key[0], dep) not in remaining for dep in task_entities[key]["value"]["depends_on"])}
        if not ready:
            # Remaining nodes include cycles and their dependent nodes. Conservatively block all.
            for key in sorted(remaining):
                ent = task_entities[key]
                present_tasks[key]["effective_acceptance"] = False
                present_tasks[key]["display_state"] = "dependency-conflict"
                issues.append({"code": "E_DEPENDENCY_CYCLE", "scope": key[0] + "/task/" + key[1], "source_ref": ent["source_ref"]})
            break
        for key in sorted(ready):
            ent = task_entities[key]
            for dep in ent["value"]["depends_on"]:
                up = present_tasks.get((key[0], dep))
                if not up or not up["effective_acceptance"]:
                    present_tasks[key]["effective_acceptance"] = False
                    # Keep historical integration separately; don't erase it as if it never happened.
                    present_tasks[key]["display_state"] = ("integrated-requires-review" if present_tasks[key]["historically_integrated"] else "dependency-wait")
                    issues.append({"code": "E_DEPENDENCY_WAIT", "scope": key[0] + "/task/" + key[1], "source_ref": ent["source_ref"]})
        remaining -= ready
    issues = sorted({canonical(x): x for x in issues}.values(), key=lambda x: (x["scope"], x["code"], canonical(x)))
    coverage = {"catalog_id": "fixture-catalog-v1", "expected_records": len(expected), "indexed_records": len(indexed),
                "unindexed_source_ids": missing, "unexpected_source_ids": extra, "complete": catalog_complete and not missing and not extra}
    state = {"schema_version": 1, "record_type": "project-state", "repository_namespace": index.repo,
             "project_id": index.project, "cursor": {"generation": index.generation, "seq": len(events)}, "as_of": as_of,
             "reducer_profile": "project-fixture-reducer-v1", "health": "degraded" if issues else "complete",
             "coverage": coverage, "entities": entities, "task_views": tasks, "issues": issues,
             "known_accepted_tasks": sum(t["effective_acceptance"] for t in tasks),
             "known_integrated_tasks": sum(t["historically_integrated"] for t in tasks)}
    state["input_fingerprint"] = digest(canonical({"events": events, "catalog": sorted(catalog, key=canonical),
        "as_of": as_of, "catalog_complete": catalog_complete, "issues": issues, "reducer": state["reducer_profile"]}))
    validate("ProjectState", state)
    return state


def safe_text(text: str) -> str:
    """Single-line display escaping, not a semantic prompt-injection detector."""
    result = []
    for ch in text:
        if unicodedata.category(ch) in ("Cc", "Cf"):
            result.append("\\u%04x" % ord(ch))
        elif ch in "\\`*_{}[]()<>#!|":
            result.append("\\" + ch)
        else:
            result.append(ch)
    return "".join(result)


def brief_items(state: dict) -> list[dict]:
    items = []
    def add(identity, text, critical, rank, resource=None):
        items.append({"id": identity, "text": text, "critical": critical, "rank": rank,
                      "refs": [] if resource is None else [resource]})
    for i, issue in enumerate(state["issues"]):
        add("issue-" + str(i), "[未核实/阻塞] " + issue["code"] + " " + issue["scope"], True, 0, issue["source_ref"])
    views = {(x["request_id"], x["task_id"]): x for x in state["task_views"]}
    for ent in state["entities"]:
        stream, value = ent["stream"], ent["value"]
        identity = "item-" + digest(canonical([ent["request_id"], stream, ent["subject_id"]]))[:24]
        prefix = ent["request_id"] + "/" + ent["subject_id"]
        critical, rank = False, 50
        if stream == "task":
            display = views[(ent["request_id"], ent["subject_id"])]["display_state"]
            text = "[任务事实] " + prefix + " " + display + "；" + value["summary"]
            critical, rank = display in ("running", "recovery-required", "integrated-requires-review", "unverified"), 30
        elif stream == "budget":
            # Exact ledger snapshot display: never add successive snapshots or group across currencies.
            text = "[预算快照] " + prefix + " " + canonical(value).decode().strip()
            critical, rank = True, 10
        elif stream in ("decision", "goal"):
            label = "已确认" if value["status"] == "CONFIRMED" else "未确认/撤销"
            text = "[" + label + "] " + prefix + " " + value["text"]
            critical, rank = stream == "goal" or value.get("safety_critical", False), 15
        else:
            text = "[来源观察] " + prefix + " " + canonical(value).decode().strip()
            rank = 40
        add(identity, text, critical, rank, ent["source_ref"])
    if not any(x["stream"] == "budget" for x in state["entities"]):
        add("budget-unknown", "[未知] 无可核验预算快照；不推定免费或有剩余额度。", True, 10)
    add("next-action", "[下一动作建议] 按来源核对阻塞/待审对象；任何执行仍由 03/07 实时准入。", True, 90)
    return sorted(items, key=lambda x: (not x["critical"], x["rank"], x["id"]))


def render_brief(state: dict, max_bytes=16384):
    validate("ProjectState", state)
    if type(max_bytes) is not int or not 256 <= max_bytes <= 262144:
        fail("E_BRIEF_LIMIT")
    items = brief_items(state)
    head = ("# 项目恢复简报\n\n" + "通知模式：pull；这是阅读辅助，不构成验收、授权或派遣许可。\n"
        + "观察时点：" + state["as_of"] + "；游标：" + state["cursor"]["generation"] + ":" + str(state["cursor"]["seq"]) + "\n"
        + "状态：" + state["health"] + "；输入版本：" + state["input_fingerprint"] + "\n\n")
    def encode(selected):
        body = []
        for item in selected:
            sources = " ".join("[来源=" + r["kind"] + ":" + r["id"] + ";sha256=" + r["sha256"] + "]" for r in item["refs"])
            body.append(safe_text(item["text"]) + " " + sources + "\n")
        omitted = len(items) - len(selected)
        foot = "\n省略条目：" + str(omitted) + "；完整清单见同版本 manifest。读取不证明理解，生成不证明送达。\n"
        return (head + "\n".join(body) + foot).encode("utf-8")
    selected = [x for x in items if x["critical"]]
    if len(encode(selected)) > max_bytes:
        fail("E_BRIEF_BUDGET_TOO_SMALL")
    # Prefix of optional items: do not skip a large high-priority item to imply smaller ones are more important.
    for item in (x for x in items if not x["critical"]):
        candidate = selected + [item]
        if len(encode(candidate)) > max_bytes:
            break
        selected = candidate
    raw = encode(selected)
    included = [x["id"] for x in selected]
    omitted = [x["id"] for x in items if x["id"] not in included]
    references = {canonical(r): r for x in selected for r in x["refs"]}
    meta = {"renderer_profile": "brief-fixture-v1", "max_bytes": max_bytes, "rendered_bytes": len(raw),
            "included_item_ids": included, "omitted_item_ids": omitted, "truncated": bool(omitted),
            "source_refs": [references[k] for k in sorted(references)]}
    validate("RenderMeta", meta)
    return raw, meta


def publish_view(index: EventIndex, state: dict, max_bytes=16384, expected_pointer=None, crash_at=None):
    """Immutable view trio, then one atomic pointer. Does not update compatibility aliases."""
    validate("ProjectState", state)
    if (state["repository_namespace"], state["project_id"], state["cursor"]["generation"]) != (index.repo, index.project, index.generation):
        fail("E_VIEW_SCOPE")
    state_bytes = canonical(state)
    brief_bytes, meta = render_brief(state, max_bytes)
    view_id = digest(canonical(["view-input-v1", digest(state_bytes), digest(brief_bytes), meta]))
    with index.writer():
        current_events, _, current_tail = index.read()
        if current_tail or state["cursor"]["seq"] != len(current_events):
            fail("E_VIEW_HEAD_CHANGED")
        pointer_path = index.root / "current.json"
        old_raw = pointer_path.read_bytes() if pointer_path.exists() else None
        actual = digest(old_raw) if old_raw is not None else None
        if actual != expected_pointer:
            fail("E_VIEW_CAS")
        if old_raw is not None:
            old_manifest = strict_load(read_resource(index.root, strict_load(old_raw)))
            if old_manifest["cursor"]["generation"] != state["cursor"]["generation"]:
                fail("E_VIEW_GENERATION")
            old_state = strict_load(read_resource(index.root, old_manifest["state_ref"]))
            if old_state["as_of"] > state["as_of"]:
                fail("E_VIEW_ROLLBACK")
            if old_manifest["cursor"]["seq"] > state["cursor"]["seq"]:
                fail("E_VIEW_ROLLBACK")
        path = "views/" + view_id
        state_ref = make_ref("project-state", view_id, path + "/state.json", state_bytes)
        brief_ref = make_ref("project-brief", view_id, path + "/brief.md", brief_bytes)
        immutable_file(index.root / state_ref["path"], state_bytes)
        if crash_at == "after_state":
            fail("E_INJECTED_CRASH")
        immutable_file(index.root / brief_ref["path"], brief_bytes)
        manifest = {"schema_version": 1, "record_type": "project-view-manifest", "cursor": state["cursor"],
                    "state_ref": state_ref, "brief_ref": brief_ref, "render_meta": meta}
        validate("ViewManifest", manifest)
        raw = canonical(manifest)
        manifest_ref = make_ref("project-view-manifest", view_id, path + "/manifest.json", raw)
        immutable_file(index.root / manifest_ref["path"], raw)
        sync_dir(index.root / "views")
        if crash_at == "before_pointer":
            fail("E_INJECTED_CRASH")
        atomic_file(pointer_path, canonical(manifest_ref))
        if crash_at == "after_pointer":
            fail("E_INJECTED_CRASH")
        return manifest_ref


def load_view(index: EventIndex):
    pointer = strict_load((index.root / "current.json").read_bytes())
    manifest = strict_load(read_resource(index.root, pointer))
    validate("ViewManifest", manifest)
    state = strict_load(read_resource(index.root, manifest["state_ref"]))
    validate("ProjectState", state)
    brief = read_resource(index.root, manifest["brief_ref"])
    if state["cursor"] != manifest["cursor"] or len(brief) != manifest["render_meta"]["rendered_bytes"]:
        fail("E_VIEW_BINDING")
    return pointer, manifest, state, brief


def record_read(index: EventIndex, manifest_ref: dict, supplied_brief_ref: dict, supplied_cursor: dict,
                session_id="session-fixture", checkpoint_id="checkpoint-fixture", recorded_at="2026-09-25T00:00:00Z"):
    manifest = strict_load(read_resource(index.root, manifest_ref))
    validate("ViewManifest", manifest)
    if supplied_brief_ref != manifest["brief_ref"] or supplied_cursor != manifest["cursor"]:
        fail("E_READ_MISMATCH")
    read_resource(index.root, supplied_brief_ref)
    identity = digest(canonical(["read-key-v1", session_id, checkpoint_id, manifest_ref]))
    receipt = {"schema_version": 1, "record_type": "brief-read-receipt", "receipt_id": identity,
        "session_id": session_id, "checkpoint_id": checkpoint_id, "manifest_ref": manifest_ref,
        "brief_ref": supplied_brief_ref, "cursor": supplied_cursor, "recorded_at": recorded_at,
        "observation": "client_acknowledged", "understanding_verified": False}
    validate("ReadReceipt", receipt)
    with index.writer():
        target = index.root / "reads" / (identity + ".json")
        if target.exists():
            old = strict_load(target.read_bytes())
            validate("ReadReceipt", old)
            # Timestamp belongs to first observation, not to idempotency fingerprint.
            if any(old[k] != receipt[k] for k in receipt if k != "recorded_at"):
                fail("E_READ_CONFLICT")
            return old
        immutable_file(target, canonical(receipt))
    return receipt

#### A.3.7 `extract_artifacts.py`：从本 Markdown 提取具名文件

<!-- artifact-file: extract_artifacts.py -->
```python
"""Extract named artifact blocks from the enhanced Markdown into a new directory.
Usage: python extract_artifacts.py DOCUMENT.md EMPTY_OUTPUT_DIRECTORY
"""
from pathlib import Path, PurePosixPath
import re
import sys


def extract(document: Path, destination: Path):
    text = document.read_text(encoding="utf-8")
    pattern = re.compile(r'<!-- artifact-file: ([^\r\n]+) -->\n```[^\r\n]*\n(.*?)\n```', re.S)
    found = pattern.findall(text)
    if not found:
        raise ValueError("no artifact blocks found")
    if destination.exists() and any(destination.iterdir()):
        raise ValueError("output directory must be empty")
    names, result = set(), []
    for name, contents in found:
        path = PurePosixPath(name)
        if path.is_absolute() or any(x in ("..", ".") for x in path.parts) or "\\" in name or ":" in name or "\0" in name:
            raise ValueError("unsafe artifact path")
        if name in names:
            raise ValueError("duplicate artifact path")
        names.add(name)
        target = destination.joinpath(*path.parts)
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_bytes((contents + "\n").encode("utf-8"))
        result.append(name)
    return result


if __name__ == "__main__":
    if len(sys.argv) != 3:
        raise SystemExit(__doc__)
    names = extract(Path(sys.argv[1]), Path(sys.argv[2]))
    print("extracted", len(names), "files")
```
